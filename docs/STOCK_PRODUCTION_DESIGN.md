# ออกแบบระบบสต็อกชิ้นส่วนรอประกอบ และระบบจัดการการผลิตจนถึงประกอบ

ฉบับร่างเพื่อพิจารณา (15/10/2569) – วิเคราะห์จากข้อมูลจริงของบริษัทที่นำเข้าโปรแกรมแล้ว และโครงสร้างของ RRS Part List Studio ณ ปัจจุบัน
ตัวเลขทุกตัวในเอกสารนี้นับจากไฟล์จริง ส่วนที่เป็น **ข้อเสนอ** ต้องให้ผู้รับผิดชอบยืนยันก่อนใช้

## 0. สรุปสั้น

1. **แยกหน้าที่ให้ชัด:** Express เป็นบัญชีสต็อกของ “สิ่งที่เป็นสินค้า” (วัตถุดิบ, ชิ้นส่วนพร้อมประกอบ, ชุดประกอบย่อย, กระบะ)
   ส่วนโปรแกรมนี้ดูแล **งานระหว่างผลิต (WIP) ตำแหน่งเก็บ และสถานะ** – ไม่ต้องเปิดรหัส Express ใหม่ทุกขั้นตอน
   (ถ้าเปิดจะได้ 325 × 5 ขั้น ≈ 1,600 รหัส)
2. **จัดชิ้นส่วนแปรรูปเป็น 10 กลุ่มประกอบ** ตามจุดที่ไปประกอบบนกระบะ – จัดอัตโนมัติได้ครบ 325/325 รหัสจากชื่อใน Express
   และตรงกับกลุ่มที่สโตร์ใช้อยู่ในไฟล์นับสต๊อค (01-0001 … 01-0011)
3. **ชิ้นส่วนใช้ทุกรุ่น (RRS-A) ทำเก็บตาม Min/Max ส่วนชิ้นเฉพาะรุ่นทำตาม SO:** เฟรมล่างเป็นชิ้นเฉพาะรุ่น 86% จึงต้องทำตาม SO
   ส่วนเสา ฝาท้าย รางรถไฟ หู และอุปกรณ์เสริมเป็นชิ้นใช้ร่วม 71–100% จึงทำเก็บรอได้
4. **ชิ้นงานเดินพร้อม “ใบงาน” ที่มี QR:** หน้างานสแกนด้วยมือถือแล้วกด “เสร็จ + จำนวน” จบใน 2 แตะ สถานะจะขึ้นในโปรแกรม บอร์ดหน้าโรงงาน และ LINE
5. **ประกอบเมื่อชุดครบ:** หน้า *ความพร้อมประกอบ* บอกต่องานว่าแต่ละชุดย่อยพร้อมกี่ % ขาดชิ้นไหน และชิ้นนั้นอยู่ขั้นไหน
6. ทำเป็น 4 ระยะ: ระยะ 1 ทำในโปรแกรมได้ทันทีโดยไม่ต้องลงทุนเพิ่ม (ข้อ 8)

สิ่งที่โปรแกรมทำได้แล้ว:
- เลือกแบบกระบะ + รุ่นย่อย แล้วได้รหัส Express
- งานผลิตต่อ SO พร้อมติดตามรายชิ้นต่อขั้น (`รอพับ 5 · รอเชื่อม 2`) และการจองสต็อกให้งาน
- ใบ PD / OU / FR / RR / AJ พร้อมบัตรสินค้า
- Min/Max และแผนตัดเหล็ก
- อ่านแบบ DWG (รหัส ชื่อ ความหนา จำนวน)

สิ่งที่ยังไม่มี: หมวด, ตำแหน่ง, ใบงาน/QR, ชุดประกอบย่อยในงานผลิต, การบันทึกจากหน้างาน และบอร์ดสถานี

  เพราะ “พื้นเรียบ” เป็นชื่อแบบกระบะด้วย เช่น “เสาหน้าพื้นเรียบ” เป็นเสา ไม่ใช่พื้น
  ตารางกฎแก้ได้ และกำหนดกลุ่มรายรหัสทับได้

### 3.3 สต็อกของชิ้นส่วน 1 รหัส = 6 ช่อง

```
 วัตถุดิบเบิกแล้ว ─► ระหว่างผลิต (แยกขั้น) ─► พร้อมประกอบ ─► จองให้งาน ─► ใช้ได้
                    รอพับ 5 · รอเชื่อม 2      (Express)      SO6910-015 4    = พร้อม − จอง
                    └──────── “จะได้” ────────┘
 ขาดสุทธิ = ต้องใช้ตามงานที่เปิด − ใช้ได้ − จะได้   → ถ้า > 0 ออกใบงานผลิตเพิ่ม
```

| ช่อง | มาจาก | มีในโปรแกรมแล้ว? |
|---|---|---|
| พร้อมประกอบ | Express / ไฟล์นับสต๊อค + FR/PD ที่บันทึกในโปรแกรม | มี |
| ระหว่างผลิตแยกขั้น | งานผลิต (จำนวนที่ผ่านแต่ละขั้น) + ใบงาน | มีรายงาน แต่ยังไม่โชว์ต่อรหัส |
| จองให้งาน | งานที่ยังไม่ปิด | มี |
| ใช้ได้ / จะได้ / ขาดสุทธิ | คำนวณ | **เพิ่ม** |

### 4.2 ลำดับงานตั้งแต่ SO ถึงส่งมอบ พร้อมผู้รับผิดชอบและเอกสาร

| 1 | ยืนยัน Order, เปิด SO | แป้ง / เป้ / เบนซ์ / แอน 1 | QT → SO | รุ่นรถ แบบงาน สเปก กำหนดส่ง ครบ |

| 3 | ตรวจความพร้อม: จองของพร้อมประกอบ, หาส่วนขาด | แอม + แอน 2 | หน้าความพร้อมประกอบ | ใช้สต็อกล่าสุด |

| 7 | ผลิตทีละขั้น ตัด → พับ → เหยียบปิด → เชื่อม → (กลึง/ส่งนอก) → ยิงทราย/ทำสี/พ่นสี | หัวหน้าสถานี | **สแกนใบงาน** (ไม่ผ่าน Express) | จำนวนดี/เสียทุกขั้น |

### 4.3 ใบงาน (Lot) – หน่วยที่ใช้ติดตาม

1 ใบงาน = ชิ้นส่วน 1 รหัส × จำนวนที่ทำพร้อมกัน × งาน (SO) หรือ “เติมสต็อก”

```
┌──────────────────────────────────────────────┐
│ ใบงาน L6910-0123          [QR]   ด่วน ●       │
│ SO6910-015 · คอกสูง 3 ราว · Toyota Champ      │
│ [รูปชิ้นงาน]  RRS-T-022-L-84-CHAMP           │
│               เสาหลัง(ซ้าย) 84 · 6 ต้น         │
│ วัสดุ SS400 t3 · แผ่น 4x8 (แผนตัด C-14)        │
│ ☐ ตัด  ☐ พับ  ☐ เชื่อม  ☐ ทำสี  → P-POST-04  │
│ กำหนดเสร็จ 20/10/2569                          │
└──────────────────────────────────────────────┘
```

- พิมพ์บนกระดาษ A6 หรือสติกเกอร์ ติดไปกับมัดชิ้นงาน มีรูปชิ้นงานจากไฟล์ Parts List All Model ช่วยลดการหยิบผิด
- ทำไม่หมดในครั้งเดียวได้ (ตัด 6 พับ 4) โปรแกรมเก็บจำนวนต่อขั้นอยู่แล้ว
- งานเสียบันทึกเป็นจำนวน “เสีย” พร้อมเหตุผล ระบบออกใบงานทำใหม่ให้อัตโนมัติ

### 4.4 สถานะ

**ใบงาน:**
```
รอวัตถุดิบ → รอตัด → กำลังตัด → รอพับ → … → รอทำสี → รอตรวจ → พร้อมประกอบ → จัดชุดแล้ว → ประกอบแล้ว
                 ↘ เสีย (ทำใหม่)   ↘ แก้ไข (rework)   ↘ ส่งนอก (กลึง/ชุบ)   ↘ พักงาน (รอแบบ/รอคำสั่ง)
```
**งาน (SO):**
```
เปิดงาน → รอวัตถุดิบ → ผลิตชิ้นส่วน → ชิ้นส่วนครบ → กำลังประกอบ → ตรวจ QC → พร้อมส่ง → ส่งมอบแล้ว
```

ทุกการเปลี่ยนสถานะบันทึกว่าใคร เมื่อไร กี่ชิ้น จึงคำนวณได้ว่าแต่ละขั้นใช้เวลาเท่าไร และงานค้างมากี่วัน

| ฝ่ายขาย (เบนซ์) | สถานะงานของลูกค้า + วันเสร็จที่คาดการณ์ | ตอบลูกค้า, ตรวจเอกสารก่อนส่ง |

## 7. ประโยชน์ที่คาดว่าจะได้

- ตอบลูกค้าได้ทันทีว่ากระบะจะเสร็จเมื่อไร ไม่ต้องเดินไปถามหน้างาน
- รู้ว่าชิ้นไหนขาด อยู่ขั้นไหน ก่อนถึงวันประกอบ จึงไม่ต้องหยุดประกอบกลางคัน
- ไม่ผลิตซ้ำของที่มีอยู่แล้ว (ยอดใช้ได้ = คงเหลือ − จอง) และไม่จมเงินกับชิ้นเฉพาะรุ่น
- นับสต็อกเร็วขึ้นด้วย QR และตำแหน่งเก็บ ยอดในระบบน่าเชื่อถือขึ้น
- ข้อมูลเวลาจริงต่อขั้นใช้ปรับปรุงคอขวดและตั้งราคาได้แม่นขึ้น

## 8. แผนทำ 4 ระยะ

| ระยะ | ทำอะไร | ต้องใช้ |
|---|---|---|
| **1. ในโปรแกรม (ทำได้ทันที)** | ประเภทสินค้า + กลุ่มประกอบ 10 กลุ่ม (อัตโนมัติ แก้ได้) ในหน้าสโตร์/รายงาน · ตำแหน่งเก็บ + พิมพ์ป้าย QR ชั้นวาง · สต็อก 6 ช่องต่อรหัส · หน้า **ความพร้อมประกอบ** ต่องาน · พิมพ์ใบงานพร้อม QR และรูป · ใบจัดชุดต่องาน | ข้อมูลที่มีอยู่แล้ว |
| **2. หน้างาน** | QR → Google Form → แท็บ ScanLog → โปรแกรมดึงผลกลับ · บอร์ด TV · แจ้งเตือน LINE OA · ปุ่มมีปัญหา | มือถือ/แท็บเล็ต, Wi-Fi, LINE OA, Google Account |
| **3. ประกอบและคิว** | BOM 3 ชั้นในงานผลิต · คิวสถานี + ตัดรวมหลายงานต่อความหนา · ขั้นยิงทราย/พ่นสี · วันเสร็จที่คาดการณ์ · แดชบอร์ดตัวชี้วัด · หน้าเว็บสแกน (ทางเลือก B) | เส้นทางการผลิตต่อชิ้น, เวลามาตรฐาน (ถ้ามี) |
| **4. เชื่อม Express เต็มระบบ** | หมวดสินค้าและคลังใน Express · รหัส FG/SUB/CON ที่ขาด · นับสต็อกวนด้วยสแกน + AJ · นำเข้าเอกสารอัตโนมัติ (ถ้า Express รับไฟล์นำเข้าได้) | การยืนยันจากบัญชี/IT |

## 9. ต้องการคำตัดสินใจ / ข้อมูลจากบริษัท

1. ยืนยัน **10 กลุ่มประกอบ** (ข้อ 3.2) และจะใช้รหัสกลุ่มของสโตร์ 01-0001 … 01-0011 คู่กันหรือไม่
2. Express ที่ใช้ **เปิดหมวดสินค้า/หลายคลังได้** หรือไม่ และ Store 1 / Store 2 เก็บอะไร (บัญชี / IT / แอน 2)
3. **รหัสกระบะสำเร็จรูป (FG)** และชุดประกอบย่อยที่ยังไม่มีรหัส
4. **ผังพื้นที่จริง**: จุดวาง WIP หลังแต่ละขั้น, ชั้นวางชิ้นส่วนพร้อมประกอบ, จุดจัดชุด
5. **เส้นทางการผลิตต่อชิ้น** (ชิ้นไหนต้องเหยียบปิด/กลึง/ส่งชุบ/ยิงทราย/พ่นสี) และสถานี/คนในแต่ละสถานี
6. **อุปกรณ์หน้างาน**: มือถือหรือแท็บเล็ตต่อสถานี, Wi-Fi ในโรงงาน, เครื่องพิมพ์สติกเกอร์ (ถ้าจะใช้สติกเกอร์แทนกระดาษ)
7. **LINE Official Account** ของบริษัท (มีอยู่แล้ว – แป้งดูแล LINE Official) จะใช้ส่งแจ้งเตือนภายในหรือเปิดบัญชีแยก
