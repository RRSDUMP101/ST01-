## ภาพจากแบบ 3D
- ปก ส่วนประกอบ ขนาด ไฟท้าย ประตูข้าง และประตูท้าย ใช้ภาพจาก `รวมหางลาก ford.igs` (Google Drive, 130 MB · ไม่เก็บใน repo) – ไฟล์มีแต่พื้นผิว (18,847 หน้า) จึงเรนเดอร์แบบ `UNIT=face`
  `UNIT=face python3 model/render.py trailer.brep model/spec.py <outdir>` (แปลง IGES → BREP ก่อนด้วย IGESControl_Reader) แล้ว `node model/svg2png.js`
- แกนของแบบ: x ขวาง (+ = ซ้ายของรถ) · y ตามยาว (+ = ท้าย, − = คานลาก) · z ขึ้น
- จากแบบ: ประตูข้างล็อกด้วยคานล็อกแนวตั้งแบบตู้คอนเทนเนอร์ (มือจับกลางบาน ลูกเบี้ยวบน–ล่าง) · ประตูท้ายมีบานพับสองฝั่ง แต่บานประตูยังไม่อยู่ในแบบ · หัวต่อพ่วง ขาตั้ง โซ่ ยังไม่อยู่ในแบบ (มีแผ่นยึดหัวต่อที่ปลายคานลาก)
- ภาพการใช้งาน (หัวต่อ โซ่ ขาตั้ง ปลั๊ก breakaway การกระจายน้ำหนัก กล้อง) ยังเป็นลายเส้น 2D ใน `drawings.py`

## ต้องให้ RRS ระบุ / ยืนยัน (ในเล่มเว้น ____ ไว้)
- น้ำหนักเปล่า ATM น้ำหนักบรรทุก น้ำหนักกดลูกบอล · ความสูงพื้นตู้และความสูงรวม
- ชนิดช่วงล่าง ขนาดยาง ลมยาง แรงขันน็อตล้อ จารบีลูกปืน · ความเร็วสูงสุดขณะลาก
- รุ่นตัวควบคุมเบรก ชุด breakaway แบตเตอรี่ และวิธีทดสอบ · หน้าที่ขาปลั๊ก 5 และ 8–12
- หัวต่อพ่วง (Ø50 / Ø70) ขาตั้งหน้า โซ่นิรภัย กลอนและมือจับประตู (ยังไม่อยู่ในแบบ 3D)
- ระยะรับประกันแต่ละชุด (อ้างสมุดรับประกัน)

- 1000008382 – ภายในตู้ (โครงเหล็ก + แผ่นผนังขาว หลังคาโครงตาราง) และช่วงล่าง 2 เพลา ล้อกระทะเหล็ก – ตรงกับแบบ ไม่ต้องแก้เนื้อหา
- ภาพในเล่มเป็นลายเส้น (ไม่ใช้ภาพถ่าย)
- 25 พ.ย. 2569: RRS แจ้งว่าปุ่มสีดำบนกล่อง Break-Away คือสวิตช์ไฟในตู้ 2 ดวง (ไม่ใช่สลักเบรกฉุกเฉิน) → แก้ภาพ 3.2 และเพิ่ม "ไฟในตู้" ในหัวข้อ 4 · สลักเบรกฉุกเฉินอยู่ที่สวิตช์บนคานลาก (ภาพ 2.2) – ให้ RRS ยืนยันตำแหน่งจริง
- 25 พ.ย. 2569 (วิดีโอ Video_Project_2 – หางลากขนรถเปิดของ RRS ลากด้วย Ford Ranger Raptor): ใช้ข้อมูลอุปกรณ์ที่เหมือนกัน
  - หัวบอล: คานบอลเสียบช่องรับชุดลาก Ford + สลักและกิ๊บ · หัวต่อแบบคันโยกมือจับดำ มีตัวบอกสถานะล็อก (เขียว) · ขาตั้งมือหมุน ตัวรัดลูกบิดแดง → 2.1
  - (แก้ตามวิดีโอชุด 1000008495–8501) สายเบรกฉุกเฉิน = สายขดสีแดงปลายตะขอ ดึงสลักห่วงของสวิตช์กล่องดำบนคานลาก → 2.2 · สายขดสีดำ → เต้ารับกลม · สายขดสีเขียว (ชาร์จแบตเตอรี่) → เต้ารับเหลี่ยม → 2.3 / 2.4
  - ระบบในกล่องเครื่องมือของหางลากขนรถ (แผงสวิตช์ 4 ช่อง สวิตช์ตัดไฟหลัก ไฟ LED) ไม่ตรงกับหางลากตู้ทึบรุ่นนี้ → 5.4 เขียนใหม่ตามวิดีโอชุด 1000008495–8501
- 25 พ.ย. 2569: ภาพทั้งเล่มเป็นภาพลายเส้นจากโมเดล 3D แล้ว (ไม่มีภาพวาด 2D เหลือ)
  - ชิ้นที่ไม่อยู่ในแบบ IGES ขึ้นโมเดล 3D เองใน `model/parts.py` ตามวิดีโอ: คานบอล + สลัก/กิ๊บ · หัวต่อคันโยก (เปิด/ล็อก) · ขาตั้งมือหมุน (ลง/ขึ้น) · โซ่นิรภัย + สายเบรกฉุกเฉิน · ปลั๊ก 12 ขา · กล่อง Break-Away · กล่องเครื่องมือ (ปิด/เปิด)
    `python3 model/parts.py <outdir>` → BREP แล้วเรนเดอร์ด้วย `model/render.py` (ขนาดเป็นค่าทั่วไป ไม่ใช่แบบผลิต)
  - การกระจายน้ำหนัก: `t_load` = แบบหางลาก + กล่องสินค้า 3 ก้อน มองด้านข้างแบบตัดผนังขวาออก
  - กล้องหางลาก: วงประบนภาพด้านท้าย (`tz_rear`)
  - `drawings.py` ไม่ได้ใช้แล้ว
