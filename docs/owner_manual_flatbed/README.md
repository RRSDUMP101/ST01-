## ยังรอ RRS ยืนยัน

- น้ำหนักกระบะแต่ละรุ่นเก๋ง · ความยาวรวมของ Super Cab / Double Cab · ความกว้างรวม
- ฝาท้ายมีโซ่หรือสลิงรั้ง และเปิดได้ 90° / 180° จริงหรือไม่ · น้ำหนักที่ฝาท้ายรับได้เมื่อเปิด 90°
- รูปแบบกลอนล็อกจริง (ภาพในเล่มเป็นภาพทั่วไป) · ขนาดประแจปรับตั้ง · วิธีปรับที่ใช้จริง
- แรงขันสลักบานพับฝา ตะแกรงกันหัว และขายึดบังโคลน (ในเล่มเว้นไว้) · จำนวนสลักจริงของฝาท้าย (ในเล่มเขียน 4) · ตะแกรงกันหัว (ในเล่มเขียน 8)
- จำนวนบานพับฝาข้างของ Super Cab / Double Cab (ในเล่มเป็นภาพตัวอย่าง 2 จุด) · ตำแหน่งกลอนหน้า/หลังของฝาข้าง
- รหัสคู่มือ (P/N) · ที่อยู่ เบอร์โทร อีเมลบริษัท
- ภาพถ่ายหรือภาพเรนเดอร์กระบะพื้นเรียบจริง (ถ้ามี จะใช้แทนภาพลายเส้น)

## หน้า 7–8 ภาพลายเส้น 2D (แก้ 23 พ.ย. 2569)
- ไม่ใช้ภาพคนจริง: หน้า 7 "รายละเอียดชิ้นส่วน" และหน้า 8 "สร้างโดย RRS" เป็นภาพลายเส้น 2D แบบเดียวกับคู่มือตัวอย่างในโฟลเดอร์ Drive "manual" (วงประ + ภาพขยาย + เลขวงกลม) วาดใน `drawings.py` (`details()`, `process_icon()`)
- รายละเอียดชิ้นส่วนอ้างอิงจากวิดีโองานประกอบจริงของ RRS คลิป C0492–C0496 (พื้นเหล็กเจาะรูกันลื่น บานพับแผ่นที่ขอบพื้น กล่องไฟท้ายมุมกระบะ ตะแกรงกันหัวแผ่นเจาะรูหกเหลี่ยม)
- ดูคลิป C0509–C0553 ครบแล้ว (21 พ.ย. 2569 จากเซสชันบนเครื่องที่เก็บคลิป) ไม่มีภาพกระบะพื้นเรียบ จึงคงภาพวาดในหัวข้อ 2–6 ไว้ทั้งหมด
  - C0509–C0533: งานหางลาก (ใส่เพลา แหนบ ขาแขวน เชื่อมและเจียรโครง) ตัดเลเซอร์ และพับ CNC
  - C0534–C0553: งานหางลากต่อ (โครงเพลาคู่บนขาตั้ง วัดและจับยึดโครง ใส่หัวลาก ตรวจโครงแบบบันได)
  - ไฟล์ C0534–C0553 ในชุดที่คัดลอกครั้งแรกเสีย (ข้อมูลเป็น FF ทั้งไฟล์ ไม่มี moov atom) ต้องใช้ชุดที่คัดลอกจาก Drive ใหม่
- ยังไม่ได้ดู MOV ที่ใหญ่กว่า 10 MB และคลิปก่อน C0486 / หลัง C0553
- ต้องยืนยันกับ RRS: ชนิดสีของกระบะรุ่นนี้

## ภาพจากแบบ 3D (แก้ 23 พ.ย. 2569)
- ภาพประกอบเกือบทั้งเล่มเป็นภาพลายเส้นซ่อนเส้นหลัง (hidden-line) จากแบบ 3D ของ RRS `พื้นเรียบ Ford.stp` (Google Drive) ทำตามแบบคู่มือตัวอย่างในโฟลเดอร์ Drive "manual": เส้นดำ วงประ เลขวงกลม ลูกศร และภาพขยาย
- ไฟล์ STEP ไม่เก็บใน repo; ภาพเรนเดอร์อยู่ใน `model/*.png` พร้อมค่าการฉาย `model/*.json` และสคริปต์ `model/render.py` + `model/spec.py` (ใช้ `pip install cadquery-ocp`) และ `model/svg2png.js`
  - แปลง STEP เป็น BREP ครั้งเดียว แล้ว `python3 model/render.py flat.brep model/spec.py <outdir>` จากนั้น `node model/svg2png.js <outdir>/<view>.svg model/<view>.png 1600`
- `model.py` วางวงประ / เลข / ลูกศรจากพิกัด 3D (มม.: X ไปท้ายรถ, Y ขึ้น, Z ไปฝั่งขวา) ลงบนภาพ
- ภาพฝาท้ายเปิด 90° / 180° ฝาข้างเปิด และมือจับปลดล็อก ได้จากการหมุนชิ้นส่วนในโมเดลรอบแนวบานพับ / แกนมือจับ
- จากโมเดล: บานพับฝาท้าย 3 จุด (z = −637, −2, 633) · บานพับฝาข้าง 3 จุด ห่างกัน 900 มม. · สลักตะแกรงกันหัว 8 ตัว · จุดผูกรัด 8 จุด · พื้นเหล็ก 3 แผ่น (ไม่ใช่แผ่นเจาะรู) · มือจับกลอนแบบคันโยกที่มุมกระบะ
- ยังเป็นภาพวาดเดิม เพราะในโมเดลไม่มีชิ้นส่วนนี้ / ไม่ใช่รุ่นนี้: สลิงรั้งฝาท้าย (หัวข้อ 4 และหน้าเพื่อการขับขี่ปลอดภัย) · ภาพด้านบน Super Cab / Double Cab · ฝาข้าง 2 บานพับของ Super / Double Cab
- ต้องยืนยันกับ RRS: กระบะรุ่นนี้มีสลิงรั้งฝาท้ายหรือไม่

## 6.5 คอกเสริม (เพิ่ม 23 พ.ย. 2569)
- 3 หน้า (27–29): ภาพแยกชิ้นจากแบบ 3D (ยกคอกขึ้น 420 มม.) + ตารางชิ้นส่วน · ภาพขยายจุดยึด ④⑤⑥ และกระบะเมื่อไม่มีคอก · ขั้นตอนถอด 6.5.1 / ประกอบ 6.5.2
- จากแบบ 3D: คอกข้าง ขวา/ซ้าย · คอกท้าย · ราวท่อ · สลัก M12×1.25 + แหวน ISO 7090-12 + น็อต ยึดแผ่นยึดคอกกับขอบบนฝา (ข้างละ 3 · ท้าย 3) · สลักเสียบ + กิ๊บล็อก มุมหลัง 2 และมุมหน้า (กับเสาตะแกรงกันหัว) 2
- วิดีโอ 1000008358.mp4 (กระบะจริง ยังไม่ติดคอก) ตรงกับภาพ `norack` จากแบบ: ฝาเตี้ย ตะแกรงกันหัวหกเหลี่ยม พื้นเหล็กลายกันลื่น ห่วงผูกรัดแบบฝังในพื้น และรูยึดบนขอบบนฝา
- ต้องยืนยันกับ RRS: แรงขันสลักยึดคอก · น้ำหนักคอกแต่ละชิ้น · ขาราวท่อยึดกับพื้นหรือคอกอย่างไร (ในแบบ ขาราวท่อลงถึงระดับพื้น)
