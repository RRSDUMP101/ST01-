## 1. โครงสร้างที่พบ

### สินค้าและ BOM
- **สินค้า**: กระบะดั้มพ์สำหรับรถกระบะ
  - ตามแบบตัวกระบะ: คอกสูง 4 / 3 / 2 ราว, คอกเตี้ย, พื้นเรียบ, + รางรถไฟ
  - × รุ่นรถ: Toyota Revo/Vigo, Toyota Champ, Mitsubishi, Isuzu, Nissan
  - × ความยาวกระบะ: 2.30 / 2.40 / 2.50 ม.
- **BOM 2 ชั้น**:
  - กระบะ 1 คัน = เฟรมล่าง + เฟรมบน + ชิ้นส่วนตัวกระบะ (30–40 แถว)
  - เฟรมบน/ล่างของแต่ละยี่ห้อมีแท็บ BOM ของตัวเอง (8–9 แถว)
- **ชิ้นส่วนผลิตเอง** (RRS-…, 325 รหัสใน Express) ทำจากวัตถุดิบ 148 รหัส:
  - เหล็กแผ่น 01-B00 หนา 1.2–25 มม. ขนาด 4x8, 5x10 และขนาดตัดพิเศษ (1524x2515 ฝาข้างพื้นเรียบ, 1524x2105 ฝาข้างดั้มพ์, 1524x1710)
  - ท่อ 04-B00, แฟลตบาร์ 01-FB0, เพลา 01-W00, เหล็กราง 08-R00 ฯลฯ
- **รหัสชิ้นส่วน**: `RRS-<รุ่น>-<เลข 3 หลัก>-<ข้าง>-<ขนาด>-<รุ่นย่อย>`
  - เลขชิ้นส่วนเดียวกันทุกรุ่นรถ (024 = บังอาย, 102 = เสาหลัง)
  - แต่ไฟล์แบบกระบะใช้รหัสฐาน (RRS-T-024) และไฟล์นับสต๊อคใช้รหัสอีกระบบ (01-0010-…)

### ขั้นตอนการผลิต
- ขั้นที่เห็นในหมายเหตุไฟล์นับสต๊อค: **รอตัด → รอพับ → รอเหยียบปิด → รอเชื่อม → พร้อมใช้งาน** และ **โรงกลึง** (ส่งงานกลึงข้างนอก)

### สโตร์และการบันทึกใน Express
| เอกสาร | ใช้ทำอะไร |
|---|---|
| **PD** จ่ายวัตถุดิบเพื่อผลิต (เลขที่ PD0000503) | เบิกวัตถุดิบเข้าผลิต |
| **OU** จ่ายสินค้าใช้ภายใน | จ่ายของใช้ภายใน |
| สต็อกชิ้นส่วนสำเร็จ | นับเป็นชิ้น / ต้น / ชุด |
| อะไหล่กระบะ | นับเป็นคัน |
| สต๊อกเหล็ก | สมุดยกมา / รับ / จ่ายรายวัน ไม่มีรหัส |

### ข้อมูลที่มีจริงตอนนี้
- **ประวัติการใช้**: สต๊อกเหล็กมีช่องจ่ายรายวันเดือน 07/2568 (27 วันทำงาน) แต่บันทึกจ่ายจริงเพียง **1 รายการ**
- **Min/Max**: คอลัมน์ Minimum ในไฟล์นับสต๊อคว่างทุกแถว
- **ราคา**: ราคามาตรฐานใน Express เป็น 0.000 ทุกรหัส
