## ยังรอ RRS ยืนยัน

- น้ำหนักกระบะแต่ละรุ่นเก๋ง · ความยาวรวมของ Super Cab / Double Cab · ความกว้างรวม
- ฝาท้ายมีโซ่หรือสลิงรั้ง และเปิดได้ 90° / 180° จริงหรือไม่ · น้ำหนักที่ฝาท้ายรับได้เมื่อเปิด 90°
- รูปแบบกลอนล็อกจริง (ภาพในเล่มเป็นภาพทั่วไป) · ขนาดประแจปรับตั้ง · วิธีปรับที่ใช้จริง
- แรงขันสลักบานพับฝา ตะแกรงกันหัว และขายึดบังโคลน (ในเล่มเว้นไว้) · จำนวนสลักจริงของฝาท้าย (ในเล่มเขียน 4) · ตะแกรงกันหัว (ในเล่มเขียน 8)
- จำนวนบานพับฝาข้างของ Super Cab / Double Cab (ในเล่มเป็นภาพตัวอย่าง 2 จุด) · ตำแหน่งกลอนหน้า/หลังของฝาข้าง
- รหัสคู่มือ (P/N) · ที่อยู่ เบอร์โทร อีเมลบริษัท
- ภาพถ่ายหรือภาพเรนเดอร์กระบะพื้นเรียบจริง (ถ้ามี จะใช้แทนภาพลายเส้น)

## ภาพจริงจากงานประกอบ (เพิ่ม 21 พ.ย. 2569)
- หน้า 7 "ภาพกระบะจริง" และหน้า 8 "สร้างโดย RRS" ใช้ภาพนิ่งจากวิดีโองานประกอบจริงของ RRS (Google Drive โฟลเดอร์ Footage / insert ในโรงงาน2) เก็บไว้ใน `img/`
- ภาพกระบะพื้นเรียบมาจากคลิป C0492–C0496 (พื้นเหล็กเจาะรูกันลื่น บานพับแผ่นที่ขอบพื้น กล่องไฟท้ายมุมกระบะ เสาตะแกรงกันหัว) ภาพกระบวนการผลิตมาจาก C0488–C0506, IMG_7226, IMG_7312, IMG_7995
- ดูคลิป C0509–C0553 ครบแล้ว (21 พ.ย. 2569 ดึงภาพนิ่งคลิปละ 4–5 ภาพ) ไม่มีภาพกระบะพื้นเรียบ จึงคงภาพวาดในหัวข้อ 2–6 ไว้ทั้งหมด
  - C0509–C0533: งานหางลาก (ใส่เพลา แหนบ ขาแขวน เชื่อมและเจียรโครง) ตัดเลเซอร์ และพับ CNC
  - C0534–C0553: งานหางลากต่อ (โครงเพลาคู่บนขาตั้ง วัดและจับยึดโครง ใส่หัวลาก ตรวจโครงแบบบันได)
  - ไฟล์ C0534–C0553 ในชุดที่คัดลอกครั้งแรกเสีย (ข้อมูลเป็น FF ทั้งไฟล์ ไม่มี moov atom) ต้องใช้ชุดที่คัดลอกจาก Drive ใหม่
- ยังไม่ได้ดู MOV ที่ใหญ่กว่า 10 MB และคลิปก่อน C0488 / หลัง C0553 ถ้ามีขั้นตอนเปิดฝา ใส่สลิง หรือถอดชิ้นส่วน ให้นำมาแทนภาพวาดในหัวข้อ 2–6
- ต้องยืนยันกับ RRS: ชนิดสีของกระบะรุ่นนี้ (ภาพพ่นสีฝุ่นเป็นสายพ่นสีของโรงงาน)
