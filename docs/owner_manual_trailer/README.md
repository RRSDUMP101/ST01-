## ภาพจากแบบ 3D – รอไฟล์ STEP
zip มีแต่ไฟล์ ZW3D (.Z3) ซึ่งอ่านได้แค่กล่องขอบเขต · ให้ export จาก ZW3D: เปิด "รวมหางลาก ford" → File → Export → STEP (.stp)
ได้ไฟล์แล้วใช้ `../owner_manual_flatbed/model/render.py` ทำภาพลายเส้นทุกมุม (ประตูเปิด หัวต่อ ล้อ ไฟ) แทนภาพ 2D แบบเล่มกระบะ

## ต้องให้ RRS ระบุ / ยืนยัน (ในเล่มเว้น ____ ไว้)
- น้ำหนักเปล่า ATM น้ำหนักบรรทุก น้ำหนักกดลูกบอล · ความสูงพื้นตู้และความสูงรวม
- ชนิดช่วงล่าง ขนาดยาง ลมยาง แรงขันน็อตล้อ จารบีลูกปืน · ความเร็วสูงสุดขณะลาก
- รุ่นตัวควบคุมเบรก ชุด breakaway แบตเตอรี่ และวิธีทดสอบ · หน้าที่ขาปลั๊ก 5 และ 8–12
- หัวต่อพ่วง (Ø50 / Ø70) ขาตั้งหน้า โซ่นิรภัย กลอนและมือจับประตู (ยังไม่อยู่ในแบบ 3D)
- ระยะรับประกันแต่ละชุด (อ้างสมุดรับประกัน)
