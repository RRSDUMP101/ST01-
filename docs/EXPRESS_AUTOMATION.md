# นำข้อมูลเข้า Express: เทียบวิธี และระบบคีย์อัตโนมัติ

Express (NewRWT) เป็นโปรแกรมบนฐานข้อมูล Visual FoxPro (ไฟล์ .DBF บน `\\<เครื่องเซิร์ฟเวอร์>\<โฟลเดอร์แชร์>\ExpressA\…` – แต่ละบริษัท/ปีเป็นโฟลเดอร์ เช่น `ffff`, `RRSDP69`)
**ไม่มี API** และ **นำเข้าเอกสารซื้อ/ขาย/เบิก จากโปรแกรมอื่นไม่ได้** (ข้อมูลจากตัวแทนจำหน่าย: นำเข้าได้เฉพาะข้อมูลหลัก
เช่น สินค้า ผู้จำหน่าย ผ่าน Excel ที่ต้องแปลงด้วย Visual FoxPro)

## 1. เทียบ 5 วิธี

| วิธี | ทำอย่างไร | ข้อดี | ข้อเสีย / ความเสี่ยง | สรุป |
|---|---|---|---|---|
| A. คีย์เองจากไฟล์ส่ง Express | หน้า Express → **ส่งออกไฟล์ส่ง Express** (ชีทละใบตามหน้าจอ) แล้วคีย์ | ปลอดภัย ไม่ต้องตั้งค่า | ช้า คีย์ผิดได้ | ใช้ได้ทันที (มีแล้ว) |
| B. นำเข้าข้อมูลหลักของ Express (Excel) | ทะเบียนสินค้า/ผู้จำหน่าย ผ่านเครื่องมือของ Express/ตัวแทน | ได้ทีละมาก | **ไม่รองรับเอกสาร** PD/OU/RR/FR · ต้องให้ตัวแทนแปลงไฟล์ | เฉพาะรหัสใหม่จำนวนมาก |
| C. เขียนลงไฟล์ DBF โดยตรง | ODBC / FoxPro เขียนตารางของ Express | เร็วที่สุด | **เสี่ยงสูง**: ข้าม logic ของ Express (เลขที่, ต้นทุน FIFO, ยอดคลัง, ลงบัญชี, ดัชนี CDX, ล็อกระเบียนตอนหลายคนใช้) ข้อมูลเสียกู้ยาก หมดการดูแลจากผู้ขาย | **ไม่แนะนำ** |
| D. **คีย์อัตโนมัติ (RPA)** – แบบในคลิป AccAiBot / ACCOS RPA | โปรแกรมพิมพ์ลงหน้าจอ Express เหมือนคน (คีย์บอร์ด) | ไม่ต้องใช้ API · Express ตรวจทุกช่อง ออกเลขที่ คิดต้นทุน ลงบัญชีเอง = ปลอดภัยเท่าคนคีย์ · ใช้กับ Express บน Server เดิม | ต้องตั้งลำดับการกดให้ตรงหน้าจอครั้งแรก · ห้ามใช้เครื่องระหว่างคีย์ | **แนะนำ** (สร้างแล้ว) |
| E. อ่าน DBF แบบอ่านอย่างเดียว | อ่านยอดคงเหลือ/เลขที่เอกสารจาก Express กลับมา | ไม่แตะข้อมูล · ได้เลขที่ Express อัตโนมัติ | ต้องรู้โครงสร้างตารางของรุ่นนี้ (ต้องมีสำเนาโฟลเดอร์ข้อมูลมาวิเคราะห์) | ขั้นถัดไป |

**ที่ใช้ร่วมกันดีที่สุด:** D (ส่งเข้า) + A (สำรอง/ตรวจ) + นำเข้ารายงาน Express (กลับ, มีแล้ว) → ต่อไป E เพื่ออ่านเลขที่กลับเอง

## 2. คีย์เข้า Express อัตโนมัติ (ในโปรแกรม)

**ลองก่อนด้วยตัวอย่าง:** หน้า Express → การ์ด ส่งเข้า Express → **ฝึกคีย์ (ตัวอย่าง)…** (ใบตัวอย่าง PD, OU, RR, JU พิมพ์ลง Notepad ให้ดู
– กด เปิด Notepad ลองก่อน แล้ว เริ่มคีย์ · ไม่มีอะไรเปลี่ยนในโปรแกรม/Express) และ **ไฟล์ตัวอย่าง…** (หน้าตาไฟล์ส่ง Express)

หน้า **Express → ส่งเข้า Express → คีย์เข้า Express อัตโนมัติ…** (บน Windows เครื่องที่เปิด Express)

1. เปิด Express ที่หน้าจอเอกสารชนิดนั้น (เช่น 4.สินค้า → PD - จ่ายวัตถุดิบเพื่อผลิต)
2. ติ๊กใบที่จะคีย์ (ใบที่ **คีย์แล้ว รอเลขที่** ไม่ถูกติ๊ก กันคีย์ซ้ำ) → **เริ่มคีย์เข้า Express**
3. โปรแกรมพิมพ์: เพิ่มใหม่ → แผนก → หมายเหตุ (งาน/SO + หมายเหตุ) → วันที่ → รายการสินค้า <F8> → รหัส/คลัง/จำนวน ทีละบรรทัด
4. **หยุดก่อนบันทึกทุกใบ** ({STOP}): ตรวจในหน้าจอ แล้วกดบันทึกใน Express เอง → ใส่เลขที่ที่ Express ออกให้ → OK = คีย์ใบถัดไป
5. ใบที่ได้เลขที่แล้วออกจากรายการ ส่งออก/ประวัติมีเลขที่ Express

**ความปลอดภัย:** หยุดทันทีเมื่อ (1) เลื่อนเมาส์ไปมุมซ้ายบนสุดของจอ (2) หน้าต่าง Express ไม่ได้อยู่ด้านหน้า (ไม่พิมพ์ผิดที่)
(3) กด **หยุด** (4) ชื่อหน้าต่าง Express บอกหน้าจออื่น เช่นเปิด OU ค้างไว้แต่ใบเป็น PD – Express เขียนหน้าจอไว้ในแถบบนสุด
(`Express Accounting - PD - จ่ายวัตถุดิบเพื่อผลิต`) โปรแกรมหยุดก่อนพิมพ์ใบนั้น (JU ของ Express = ใบปรับยอด AJ ในโปรแกรม) ·
ไม่บันทึกแทนคน (เว้นแต่แก้แบบการกดให้กดบันทึกเอง) · ไม่แตะไฟล์ข้อมูลของ Express

**หน้าต่างถาม ขึ้นทับ Express (อยู่บนสุดเสมอ)**
* **ตรวจหน้าจอ Express ก่อนคีย์** (ใบแรกของแต่ละชนิด) – ขึ้นกลางจอด้านบน: ① ชื่อหน้าต่างที่จะพิมพ์ และ ✓ *เป็นหน้าจอ PD ถูกต้อง*
  (หรือ ⚠ ให้ตรวจด้วยตา) ② หน้าจอว่าง ไม่มีใบค้าง ③ จะพิมพ์อะไร: แผนก วันที่ จำนวนรายการ คลัง หมายเหตุ → **✓ ถูกต้อง – เริ่มคีย์ใบนี้** (Enter) / **หยุด**
* **ตรวจแล้วบันทึกใน Express** (ทุกใบ) – ขึ้นที่มุมขวาล่าง ไม่แย่งแป้นพิมพ์จาก Express: ตรวจ → กดบันทึกใน Express → กดปุ่มในหน้าต่างนี้
* **ทดลองทีละขั้น** (ติ๊กในหน้าต่างคีย์) – หน้าต่างเล็กมุมจอบอกว่าจะ *พิมพ์ “01”* / *กด Enter* อะไรต่อ ทีละขั้น:
  **ทำขั้นนี้ ▶** · **ทำต่อจนจบใบ ▶▶** · **หยุด** – ดูว่าเคอร์เซอร์ใน Express อยู่ช่องที่ถูกต้องก่อนทุกขั้น ใช้ตั้งลำดับการกดครั้งแรก

**หยุดเมื่อ Express เปิดหน้าต่างอื่นขึ้นมา** – หน้าค้นหาสินค้า/แผนก (รหัสที่พิมพ์ไม่มีใน Express) หรือข้อความเตือน (เช่น จำนวนติดลบ):
โปรแกรมหยุดทันทีก่อนพิมพ์ต่อลงไปในหน้าต่างนั้น (ครั้งแรกที่ทดลอง รหัสไม่มีในบริษัททดสอบ Express จึงเปิดหน้าค้นหา แล้ว Enter ต่อมา
เลือกสินค้าตัวแรก `10000` ทุกบรรทัด) – ปิด/ยกเลิกใบนั้นใน Express แก้ใบในโปรแกรม แล้วคีย์ใหม่

**หน้าค้นหาสินค้าของ Express** (ขึ้นหลังใส่รหัส โดยเลือกแถวของรหัสนั้นไว้แล้ว): โปรแกรมกด Enter รับแถวนั้น **เฉพาะรหัสที่มีในรายการสินค้า
Express ที่นำเข้าไว้** (หน้าสโตร์ – รายการเดียวกับที่ผลตรวจวัตถุดิบเทียบสต็อกใช้) · รหัสที่ไม่มี หรือยังไม่ได้นำเข้ารายการ: หยุด
(Enter จะได้แถวที่ใกล้ที่สุด = สินค้าผิดตัว) · ปิดได้ที่ช่องติ๊กในหน้าต่างคีย์ · ใบ PD ที่ **ร่างจากผลตรวจวัตถุดิบ** ใช้รหัสในคอลัมน์
*รหัสสินค้า* ของผลตรวจ (เช่น RRS-A-001-250 สำหรับชิ้นส่วน RRS-T-001)

**หน้าต่าง ป้อนหน่วยนับที่รับ/จ่าย** (สินค้าที่มีหลายหน่วย ขึ้นหลังใส่จำนวน): โปรแกรมใช้หน่วยที่ Express เสนอ (หน่วยของสินค้า ตัวคูณ 1.0)
แล้วกด Enter จนหน้าต่างปิด และคีย์ต่อ – ช่อง *หน้าต่าง Express ที่กด Enter ให้* (ตั้งต้น `ป้อนหน่วยนับ`) เพิ่ม/ลบชื่อหน้าต่างได้ (ผู้ดูแล/IT)
· กด Enter 5 ครั้งแล้วยังไม่ปิด หรือหน้าต่างอื่น: หยุดคีย์

**จำนวนติดลบ คีย์เป็น 0** (ติ๊กไว้ตั้งต้น) – Express ไม่รับจำนวนติดลบ ขึ้นข้อความแล้วการคีย์หยุด: บรรทัดที่ติดลบคีย์เป็น 0 และเตือนก่อนเริ่มว่าบรรทัดไหน
(ใบปรับยอด AJ ที่ต้องลดสต็อก: ตรวจ/แก้จำนวนใน Express เอง)

**ตรวจก่อนคีย์ (เตือนก่อนเริ่ม และในช่อง สิ่งที่จะพิมพ์)**
* รหัสสินค้าที่ไม่มีในรายการสินค้าของ Express ที่นำเข้าไว้ในโปรแกรม – ตรวจว่าเปิด **บริษัท** ใน Express ถูก (แถบล่างของ Express บอกโฟลเดอร์บริษัท)
* **รหัสแผนกใน Express** (ใส่ครั้งเดียว เช่น `ST01, 08, ACC, SEL1, SET, SET1, ST1` จากหน้าค้นหาแผนกของ Express) – ใบที่แผนกไม่ใช่รหัสเหล่านี้
  เตือน เพราะ Express จะเปิดหน้าค้นหาแผนกแล้วปุ่มที่กดต่อจากนั้นผิดช่องทั้งหมด · ไม่ได้ใส่รายการ: ยังเตือนเมื่อแผนกดูเป็นชื่อ (มีเว้นวรรค/ยาวเกิน 10 ตัว)
* **รหัสคลังใน Express** (เช่น `01`) · บรรทัดไม่มีรหัส / จำนวน 0 / รหัสมีช่องว่างหน้า-หลัง-ซ้อน (ต้องตรงกับรหัสใน Express ทุกตัว เช่น `01-B00 -0005`) · หมายเหตุยาวเกินช่อง

### ตั้งลำดับการกดครั้งแรก (ทำครั้งเดียวต่อหน้าจอ)

ลำดับที่ให้มาเป็นค่าตั้งต้นจากภาพหน้าจอ Express ของบริษัท **ต้องทดลองกับหน้าจอจริงก่อน**

1. ทดลองกับ Notepad: เปิด Notepad → ในช่อง *พิมพ์ลงหน้าต่างที่ชื่อมี* ใส่ `Notepad` (หรือ `Untitled`) → เริ่มคีย์ → ดูสิ่งที่พิมพ์
2. ทดลองกับ Express ด้วยใบเดียว + ติ๊ก **ทดลองทีละขั้น**: ก่อนทุกขั้นดูว่าเคอร์เซอร์อยู่ช่องที่จะพิมพ์ → ผิดช่อง กด หยุด แล้วแก้แบบการกด
   เช่น เพิ่ม/ลด `{ENTER}` `{TAB}` หรือ `{WAIT 800}` (ใบที่หยุดกลางคัน: ยกเลิกใบนั้นใน Express โดยไม่บันทึก)
   · ลำดับที่เคอร์เซอร์ไป (จากการทดลองจริงของบริษัท): หลัง {F4} เปิดใบใหม่ เคอร์เซอร์อยู่ที่ **เลขที่เอกสาร** (Express ใส่ `PD**NEW**`
   ให้) → {ENTER} เก็บเลขของ Express → **วันที่** → **สำหรับแผนก** (ข้าม: {ENTER} อย่างเดียว ไม่เลือกแผนก) → **หมายเหตุ** =
   เลขที่ใบงานตามด้วยแผนกในโปรแกรม เช่น `JOB-001 ตัดเลเซอร์` (ไม่มีทั้งสอง: หมายเหตุของใบ) → <F8> รายการสินค้า
   · ใบ RR (รับสินค้า) ยังไม่ได้ทดลองกับ Express จริง – ลองทีละขั้นก่อน
   **รหัส → รายละเอียด (Express เติม) → คลัง → จำนวน → หน่วย (Express เติม) → ราคาต่อหน่วย → จำนวนเงิน** · จุดที่ควรดูตอนทดลอง:
   หลัง [จำนวน] กด Enter กี่ครั้งถึงขึ้นบรรทัดใหม่ และช่องคลังที่ Express ใส่ 01 ไว้ให้แล้ว พิมพ์ทับหรือต่อท้าย
3. ปุ่มที่ใช้: `[แผนก] [หมายเหตุ] [วันที่] [งาน] [ผู้จำหน่าย] [อ้างอิง]` · บรรทัด `[รหัส] [คลัง] [จำนวน] [หน่วย] [ราคาต่อหน่วย]` ·
   `{ENTER} {TAB} {ESC} {DOWN} {F4} {F8} {F10} {CTRL+S} {TAB 3}` · `{WAIT 500}` · `{STOP}`
4. ภาษาไทยเป็นตัวอ่านไม่ออก: ติ๊ก **พิมพ์ภาษาไทยด้วยการวาง (Ctrl+V)** หรือสลับแป้นพิมพ์เป็นไทยในหน้าจอ Express ก่อนเริ่ม

## 3. ขั้นต่อไป (ต้องการข้อมูลจากบริษัท)

* สำเนาโฟลเดอร์ข้อมูล Express (คัดลอกตอนปิดโปรแกรม ไม่ใช้ตัวจริง) → ทำ **อ่าน DBF อย่างเดียว**: เลขที่ Express ของใบที่คีย์ ยอดคงเหลือสด
  ตรวจว่าใบในโปรแกรมกับใน Express ตรงกัน (วิธี E)
* วิดีโอ/ลำดับปุ่มจริงของหน้าจอ PD, OU, RR (ใบเดียว) → ปรับค่าตั้งต้นของแบบการกดให้ใช้ได้ทันที
