# ปรับเมนูและขั้นตอนงาน: จากแบบ DWG ถึงตัดเลเซอร์และสโตร์

## 1. ปัญหาที่พบ (ก่อนปรับ)

| ปัญหา | ตัวอย่างในโปรแกรมเดิม | ผลต่อผู้ใช้ |
|---|---|---|
| ปุ่มเดียวกันอยู่หลายที่ | **นำเข้าแบบ DWG** อยู่ 4 ที่ (ภาพรวม, แบบ 2D, Part List, เมนูไฟล์) · **เปิดงานผลิต** 4 ที่ (2 ปุ่มในหน้างานผลิต, หน้าแบบกระบะ, เมนู) · **เทียบ Rev.** 3 ที่ | ไม่แน่ใจว่าควรกดที่ไหน กดแล้วผลต่างกันไหม |
| เมนูซ้ายไม่เรียงตามงานจริง | แบบกระบะคั่นกลางระหว่าง Part List กับงานผลิต · Express/Google Sheets อยู่ระดับเดียวกับขั้นตอนงาน | ไม่รู้ว่าทำหน้าไหนก่อน-หลัง |
| ลำดับขั้นในหน้าภาพรวมขัดกับระบบ | ขั้น 2 “ตรวจวัตถุดิบ + ตัดเลเซอร์” มาก่อนขั้น 3 “เปิดงานผลิต” แต่การตัดจริงต้องมีงานผลิตก่อน | ตัดจาก Part List แล้วไม่ไปบันทึกในงาน |
| ที่มาของการตัด 2 แบบดูเท่ากัน | “งานผลิต” กับ “Part List ปัจจุบัน × จำนวนคัน” | ใช้ผิดแบบ ตัดซ้ำหรือไม่บันทึกงาน |
| เมนูส่งออกของหน้าตัดเหล็ก | แผนตัด Excel / DXF ZWCAD / แพ็กเลเซอร์ ปนกัน ไฟล์ที่ใช้ตัดจริงอยู่ล่างสุด | ส่งไฟล์ผิดให้เครื่อง |
| ไม่มีใครบอกขั้นต่อไป | หลังนำเข้าแบบ ต้องรู้เองว่าต้องไปเปิดงาน แล้วไปหน้าตัดเหล็ก แล้วกลับมาบันทึก | ผู้ใช้ใหม่หลงทาง |

## 2. โครงใหม่: เส้นทางงานเดียว 6 ขั้น

```
ภาพรวม / เริ่มงาน
ขั้นตอนงาน
  ① แบบ 2D (DWG/DXF)   นำเข้าแบบ อ่านรหัส ชื่อ ความหนา จำนวน · เก็บรูปคลี่
  ② Part List           ตรวจ/แก้รายการ · ตรวจวัตถุดิบเทียบสต็อก
  ③ งานผลิต (SO)        เปิดงาน (ปุ่มเดียว เลือกที่มา) · ติดตามรายชิ้น · ใบงาน QR · ความพร้อมประกอบ
  ④ ตัดเลเซอร์          วางแผนตัด → ตรวจก่อนตัด → คิว (ไฟล์เครื่อง / บันทึกตัดเสร็จ)
  ⑤ สโตร์ / ชิ้นส่วนพร้อมประกอบ   สต็อก · ตรวจวัตถุดิบ · Min/Max · ชิ้นส่วนแยกกลุ่ม
  ⑥ เบิก / รับ สต็อก    ตรวจและบันทึกใบที่ระบบร่าง → คีย์ Express
ข้อมูลหลัก & เชื่อมต่อ
  แบบกระบะมาตรฐาน · Express · Google Sheets · ตั้งค่า
```

**แถบขั้นตอน (บนทุกหน้าของขั้น ①–⑥):** บอกว่าอยู่ขั้นไหน (สีน้ำเงิน) ขั้นไหนมีงานค้าง (สีส้ม พร้อมจำนวน
เช่น “รอวาง 73 ชิ้น · คิว 0”, “รอรับเข้า 1”, “ร่าง 2 ใบ”) คลิกขั้นเพื่อไปหน้านั้น
และมี **ปุ่ม “ขั้นต่อไป”** ปุ่มเดียว ที่โปรแกรมเลือกจากข้อมูลจริง (คีย์ลัด Ctrl+Enter)

ลำดับที่โปรแกรมเลือกขั้นต่อไป:

| สถานะของข้อมูล | ขั้นต่อไป |
|---|---|
| ยังไม่มี Part List และงาน | นำเข้าแบบ DWG (เปิดหน้าต่างเลือกไฟล์ทันที) |
| มี Part List แต่ยังไม่มีงานเปิด | เปิดงานผลิตจาก Part List |
| งานมีชิ้นรอตัดที่ยังไม่อยู่ในโปรแกรมตัด | วางแผนตัดเลเซอร์ N ชิ้น |
| มีโปรแกรมรอตัด / กำลังตัด | ตัดและบันทึกผล N โปรแกรม (เปิดแท็บคิวเลเซอร์) |
| ชิ้นยังไม่ผ่านทุกขั้น | บันทึกงานพับ/เชื่อม |
| ชิ้นเสร็จแต่ยังไม่รับเข้า | รับชิ้นงานเสร็จเข้าสโตร์ |
| มีเอกสารร่าง | ตรวจและบันทึกเอกสารร่าง |
| ทุกอย่างเรียบร้อย | ดูความพร้อมประกอบ |

## 3. สิ่งที่ตัดความซ้ำซ้อน

| เรื่อง | เดิม | ใหม่ |
|---|---|---|
| นำเข้าแบบ DWG | 4 ที่ | ภาพรวม + หน้าแบบ 2D (+ เมนูไฟล์ และลากไฟล์มาวาง) · หน้า Part List เปลี่ยนเป็น “เพิ่มรายการ ▾” (ตาราง BOM / แบบกระบะ) |
| นำเข้าตาราง BOM | ภาพรวม + Part List + เมนู | Part List + เมนู |
| เปิดงานผลิต | 2 ปุ่มแยกในหน้างานผลิต | ปุ่มเดียว “+ เปิดงานผลิต ▾” เลือก จาก Part List / จากแบบกระบะ |
| เทียบ Rev. | แบบ 2D + Part List + เมนู | แบบ 2D + เมนู |
| ตรวจวัตถุดิบ | อยู่แต่ในหน้าสโตร์ | ปุ่ม “ตรวจวัตถุดิบเทียบสต็อก” ในหน้า Part List (ผลแสดงในหน้าสโตร์) |
| ที่มาของการตัด | 2 ตัวเลือกเท่ากัน | “งานผลิตที่ยังตัดไม่ครบ (ใช้ตัดจริง)” / “ทดลองคำนวณจาก Part List (ยังไม่เปิดงาน)” |
| ส่งออกหน้าตัดเลเซอร์ | ไฟล์ตัดจริงอยู่ล่างสุด | ไฟล์ให้เครื่องเลเซอร์อยู่บนสุด แผน Excel/DXF ZWCAD เป็นไฟล์ดูประกอบ |
| ใบเบิก/รับ | “จาก Part List × จำนวนคัน” ไม่บอกว่าใช้เมื่อไร | “ร่างจาก Part List (ยังไม่เปิดงาน)” + คำแนะนำว่ามีงานแล้วให้สร้างจากหน้างานผลิต |
| เมนูบน | “งานผลิต / สโตร์” ไม่เรียง | “ขั้นตอนงาน” เรียง ①–⑥ และ “ทำขั้นต่อไป ›” |

### จำนวนคัน: แก้ได้ที่เดียว (ทำแล้ว)

| ข้อมูล | แก้ที่ | หน้าอื่น |
|---|---|---|
| จำนวนคันของ Part List (ยังไม่เปิดงาน) | **หน้าภาพรวม** ช่อง “จำนวนผลิต (คัน)” | หน้าสโตร์ (ตรวจวัตถุดิบ) และหน้าตัดเลเซอร์ (ทดลองคำนวณจาก Part List) แสดงค่าอย่างเดียว พร้อมปุ่ม “แก้ที่หน้าภาพรวม ›” |
| จำนวนคันของงานที่เปิดแล้ว | **หน้างานผลิต** ช่อง “จำนวนคัน” ของงานนั้น | ตัดเลเซอร์ / ความพร้อมประกอบ / ใบเบิก ใช้จำนวนของงาน |

เปลี่ยนจำนวนคันของงาน: ทุกชิ้นคิด *จำนวนต่อคัน × คัน* ใหม่ ชิ้นที่ทำไปแล้วยังนับอยู่ (ลดคันแล้วชิ้นที่ทำเกินถือว่าเสร็จ)
ชิ้นที่จองจากสต็อกไว้คงเดิมไม่เกินที่ต้องใช้ และบันทึกในประวัติการทำงานของงาน

## 4. ระยะต่อไป (ยังไม่ได้ทำ)

- หน้าต่างนำเข้าแบบ: เมื่อกดเพิ่มเข้า Part List ให้ถามต่อทันทีว่าจะเปิดงานผลิตเลยหรือไม่
- ซ่อนหน้า/ปุ่มตามบทบาทผู้ใช้ (ผู้ออกแบบ / วางแผนผลิต / ช่างเลเซอร์ / สโตร์)
