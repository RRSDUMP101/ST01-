## 2. แนวทางที่ใช้ให้ข้อมูลตรงกัน

1. **หัวตารางชุดเดียวกันทุกที่** – สต็อกในโปรแกรมใช้ชื่อคอลัมน์ตามหน้าจอ Express:
   `รหัสสินค้า | ชื่อสินค้า | หมวด | กลุ่มบัญชี | วัสดุ | ขนาด/ความหนา | หน่วย | ยอดคงเหลือ | ราคาต่อหน่วย | Min | Max | คลัง | ชั้นเก็บ | หมายเหตุ`
   และอ่านชื่อหัวตารางแบบอื่นของแต่ละไฟล์ได้ (จำนวน, ยอดคงเหลือ (pcs.), Minimum (pcs.), กลุ่มบ/ช, หน่วยย่อย …)
2. **หลายแหล่งสต็อกพร้อมกัน** – Express, ไฟล์นับสต๊อค, สต๊อกเหล็ก, อะไหล่กระบะ, Google Sheet แต่ละไฟล์เป็น "แหล่ง" ติ๊กเลือกว่าจะใช้ตรวจวัตถุดิบ รหัสซ้ำใช้แหล่งที่อยู่บนก่อน
3. **ตารางเทียบรหัส (CodeXref)** – จับคู่รหัส Express/แบบ ↔ รหัสนับสต็อก จาก **ชื่อสินค้าที่ตรงกัน** (หรือคล้าย ≥ 90%) ให้ผู้ใช้ยืนยัน/แก้ไข แล้วการค้นหายอดคงเหลือจะตามคู่รหัสให้เอง
4. **อ่านรหัสที่พิมพ์ไม่สม่ำเสมอ** – ปรับรูปแบบรหัส (`RRS-T018` → `RRS-T-018`) แยกหลายรหัส และเทียบรหัสแบบไม่สนขีด/วงเล็บ
5. **วัตถุดิบตามหน่วยจริง** – เหล็กแผ่นในสโตร์นับเป็น "แผ่น": คิดจาก น้ำหนักชิ้นงาน ÷ น้ำหนักต่อแผ่น (ขนาดแผ่นอ่านจากชื่อ เช่น `5x10ฟุต`, `1524x3050`, `4x2530`) ยังไม่รวมเศษ
6. **Express ไม่มีการ import เอกสาร** ที่ยืนยันได้ – ไฟล์ที่ส่งออกเป็น **ร่างเรียงตามหน้าจอ Express** ให้สโตร์คีย์ (Express ออกเลขที่เอกสารเอง)

### 3.1 Parts List All Model (รหัส Express)

หน้า **Express → 3. รหัส Express ในแบบกระบะ และฟอร์ม Sheet** (หรือเมนูบน **Express**) (ต้องนำเข้า *รายงานรายละเอียดสินค้า STMASR0200* และแบบกระบะก่อน)

* **รหัสในแบบ ≠ รหัส Express**: แบบใช้รหัสฐาน `RRS-T-024` แต่ Express มีรหัสต่อรุ่น/ความสูง/ข้าง
  `RRS-T-024-L-84`, `RRS-T-024-R-84-CHAMP` … และเลขกลุ่มไม่สม่ำเสมอ (เสาหน้า = 022 หรือ 099)
  จึงจับคู่จาก **ชื่อชิ้นส่วน + คำสำคัญ** (ฝาข้าง ≠ ฝาท้าย, หน้า ≠ หลัง, บน ≠ ล่าง) **+ รุ่นรถจากชื่อแท็บ/หัวเรื่อง**
  (Toyota / Champ / Mitsu / Isuzu / พื้นเรียบ) **+ ความสูงคอก** (4 ราว = 84, 3 ราว = 80, 2 ราว = 60, คอกเตี้ย = 40)
  **+ ความยาวกระบะ** (230/240/250) และแถว `1+1` แยกเป็น **ซ้าย 1 แถว ขวา 1 แถว**
* ผลกับไฟล์จริง (14 แบบ, 300 แถวหลังแยกซ้าย/ขวา): รหัสตรง 40 · จับคู่อัตโนมัติ 98 · **ควรตรวจ 88** · ไม่พบใน Express 74
  (ชิ้นที่ยังไม่มีรหัส เช่น ปะกับ, ราวบน, ราวล่าง, เหล็กปิดเหล็กกล่อง, แผ่นปิดโครงคัตชี → 43 รหัสใหม่ในฟอร์ม)
* ปุ่ม **Parts List All Model (รหัส Express)** สร้าง Excel หนึ่งไฟล์ (อัปโหลดขึ้น Google Drive แล้ว *เปิดด้วย Google Sheets* ได้ สูตรทำงานต่อ):

| แท็บ | เนื้อหา |
|---|---|
| คำแนะนำ / สรุป | วิธีใช้ และตัวเลขสรุป (สูตร) |
| แท็บแบบกระบะ (14) | รูปแบบเดิม `ลำดับ \| รหัส \| รายการ \| ภาพประกอบ \| ขนาด \| จำนวนที่ใช้ \| หมายเหตุ` + รูป · รหัส = รหัส Express (เลือกจากรายการได้) · ชื่อใน Express, หน่วย, ยอดคงเหลือ, ราคามาตรฐาน, ตรวจรหัส = สูตร · การจับคู่, รหัสเดิมในแบบ, ตัวเลือกอื่น |
| เทียบรหัสแบบกระบะ | ทุกแถวของทุกแบบ + สถานะ (กรอง *ควรตรวจ*) – อ้างอิงแท็บแบบ จึงเปลี่ยนตามเมื่อแก้รหัส |
| ฟอร์มเพิ่มสินค้าใหม่ | ชิ้นที่ Express ยังไม่มี พร้อม **รหัสที่เสนอตามรูปแบบ Express** (`RRS-T-023-R-84-CHAMP`), หมวด 21, หน่วย, รหัสบ/ช · ตรวจรหัสซ้ำ/ยาวเกิน |
| ทะเบียนสินค้า, กลุ่มรหัส, สต็อกนับ | จาก STMASR0200 + ไฟล์นับสต๊อค (ผูกรหัส 319/324) |
| อะไหล่กระบะ (Express), สต๊อกเหล็ก (Express) | ยอดเดิม + รหัส Express ของแต่ละรายการ (จับคู่จากชื่อ + ความหนา/ขนาด) · สต๊อกเหล็กมี น้ำหนัก/แผ่น, น้ำหนักคงเหลือ, ตรวจยอด |

* ปุ่ม **ใช้รหัส Express กับแบบกระบะ**: เปลี่ยนรหัสในหน้า แบบกระบะ เป็นรหัส Express (แถวที่ไม่พบคงรหัสเดิม และหมายเหตุบอกรหัสเดิม/สถานะ)
  → Part List ที่สร้างจากแบบ, การตรวจวัตถุดิบ, ร่าง PD และแท็บ `Models` ใน Google Sheet ใช้รหัสเดียวกับ Express
* อ่านไฟล์นี้กลับเข้าโปรแกรมได้: **ไฟล์ → นำเข้า → ไฟล์ Parts List All Model** (แท็บแบบกระบะอ่านรหัส Express ได้ตรง)

## 4. เมนูที่เพิ่ม

* แถบซ้าย: **แบบกระบะ** (คลัง Part List มาตรฐานพร้อมรูป → สร้าง/เพิ่ม Part List × จำนวนชุด, บันทึก Part List เป็นแบบใหม่) และ **Express** (นำเข้า, ส่งออกร่าง, ตรวจรหัส, เทียบกับ Google Sheet, ตารางเทียบรหัส)
* หน้า **สโตร์ / คลังสินค้า**: รายการแหล่งข้อมูลสต็อก (ติ๊กเลือก), ส่งออกรูปแบบไฟล์นับสต๊อค, ใบจ่ายเหล็ก
* หน้า **Google Sheets**: แท็บใหม่ `CodeXref` (ตารางเทียบรหัส) และ `Models` (แบบกระบะทุกแบบในตารางเดียว)
* เมนูบน **Express**: นำเข้า / ร่าง PD / ร่างใบขอซื้อ / สินค้าใหม่ / ตรวจรหัส / ตารางเทียบรหัส · เมนู **ไฟล์ → นำเข้า/ส่งออก** มีไฟล์ของบริษัทครบ
* Part List แสดง **รูปชิ้นส่วน** (จากไฟล์ Parts List All Model) ในตารางและเมื่อชี้เมาส์

## 5. ลำดับงานที่แนะนำ

1. นำเข้า **7. Parts List All Model** (หน้า แบบกระบะ) – ได้แบบกระบะ + สต๊อกเหล็ก + อะไหล่กระบะ
2. นำเข้า **10. นับสต๊อค** (หน้า สโตร์) และ **ทะเบียนสินค้าจาก Express** (หน้า Express)
3. หน้า Express → ตารางเทียบรหัส → **สร้างจากชื่อสินค้า** → ตรวจ แล้วใส่ Y ในช่องยืนยันแล้ว (ส่งขึ้น Google Sheet ให้ทุกฝ่ายใช้ชุดเดียวกัน)
4. หน้า แบบกระบะ → เลือกแบบ → **สร้าง Part List ใหม่จากแบบนี้** → ใส่จำนวนคัน
5. หน้า สโตร์ → **ตรวจวัตถุดิบเทียบสต็อก** → อัปเดตสถานะ → ร่าง PD / ใบขอซื้อ / ใบจ่ายเหล็ก

## 6. ที่ยังต้องยืนยันกับข้อมูลจริง

* ไฟล์ Excel/CSV ที่ Express ส่งออกได้จริงจากหน้ารายการสินค้า/รายงานสินค้าคงเหลือ (ขอไฟล์ตัวอย่าง 1 ไฟล์) – ตอนนี้รองรับหัวตารางตามที่เห็นบนหน้าจอและรายงานแบบข้อความ
* รูปแบบรายงานสินค้าคงเหลือของ Express ที่มีตัวเลข (ในวิดีโอเห็นเฉพาะแบบฟอร์มตรวจนับซึ่งไม่มียอด)
* หน่วยใน Express: เห็น ผน (แผ่น), สน (เส้น), ชน (ชิ้น) – หน่วยอื่นแสดงตามรหัสเดิม
* รหัส RRS ในไฟล์ Parts List All Model บางรายการไม่ตรงกับ Express (เช่น RRS-019, RRS-T018) – ใช้ไฟล์ *Parts List All Model (รหัส Express)* ตรวจแถว **ควรตรวจ** แล้วเลือกรหัส
* ข้อมูลใน Express ที่ควรแก้: `RRS-T-102-R-84-CHAMP` ชื่อ *เสาหน้า(ขวา)* แต่เลข 102 เป็นกลุ่มเสาหลัง, มี *เสาหลัง(ซ้าย) 84* สองรหัส (102 และ 103) แต่ไม่มีข้างขวา, `RRA-A-074-230-DOWN` ขึ้นต้น RRA
