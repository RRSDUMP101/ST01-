# ตรวจและแก้แบบก่อนส่งตัด · Mark · Nest · Gap

แบบ 2D ที่ส่งมาตัดมักยังไม่เรียบร้อย เช่น มุมต่อไม่สนิท เส้นยื่นเกิน เส้นพับอยู่บนเลเยอร์ตัด
หรือมีตัวเลขมุมพับ `90` ค้างอยู่ในชิ้นงาน ถ้าเครื่องเลเซอร์ได้แบบแบบนี้จะตัดผิด หรือเปิดไม่ได้เป็นชิ้นงาน
ระบบจึง **ตรวจและแก้เส้นให้เองตอนนำเข้าแบบ** และบอกทุกจุดที่แก้ จุดที่แก้เองไม่ได้จะถูกแสดงให้กลับไปแก้ในแบบ
จากนั้นใส่ **Mark · Nest · Gap** ลงในไฟล์ที่ส่งให้เครื่อง

```
นำเข้าแบบ DWG/DXF
  │  ① อ่านเส้นตัด (เลเยอร์ตัด, ข้ามเลเยอร์ DIM/TEXT/BEND/CENTER …)
  │  ② เส้นที่ปิดวงอยู่แล้ว → ใช้ได้เลย
  │  ③ เส้นที่ไม่ปิดวง → แก้อัตโนมัติ (ต่อมุม · ตัดเส้นเกิน · ลบเส้นซ้ำ · แยกเส้นพับ · ลบเส้นเกิน)
  │  ④ ตัวเลข/ตัวอักษรที่เป็นเส้นในชิ้นงาน → ลบออก · ข้อความ 90 / UP 90° R 0 → ไม่ส่งไปตัด
  ▼
แท็บ "ตรวจแบบก่อนตัด"  แก้แล้ว (เขียว) · ต้องแก้แบบ (แดง) · ข้อมูล
  ▼
คลังรูปคลี่ (เก็บเส้นพับ + ประวัติการแก้ไว้กับรหัสชิ้น)
  ▼
วางแผนตัด (Nest)   ระยะห่างตามความหนา · หมุนชิ้นที่วาดเอียง · หมุน 90°
  ▼
ไฟล์ให้เครื่อง      CUT_OUTER / CUT_INNER · MARK (รหัส, เส้นพับ) · Gap/micro-joint
```

## 1. ปัญหาในแบบ และสิ่งที่ระบบทำ

| ปัญหาในแบบ | ถ้าไม่แก้ | ระบบทำ | ผล |
|---|---|---|---|
| มุมต่อไม่สนิท (ปลายเส้นห่างกันเล็กน้อย) | ชิ้นงานหาย / เครื่องตัดไม่ครบวง | ต่อปลายเส้นที่ห่าง **ไม่เกิน 0.5 มม.** (ตั้งได้ 0.05–5 มม.) ทั้งปลายชนปลาย และปลายที่หยุดก่อนถึงเส้น | แก้แล้ว · วงกลมเขียวในภาพ |
| เส้นยื่นเกินมุม | เครื่องตัดเกินเข้าเนื้อแผ่นข้างเคียง | ตัดส่วนที่ยื่นเกินมุม (ไม่เกิน 5 มม.) ออก | แก้แล้ว |
| เส้นวาดซ้ำ / เส้นทับกัน / วงซ้อนสองชั้น | เครื่องตัดซ้ำ ขอบไหม้ | เก็บไว้เส้นเดียว | แก้แล้ว |
| เส้นพับบนเลเยอร์ตัด (เส้นตรงผ่าชิ้นจากขอบถึงขอบ) | เครื่องตัดชิ้นขาดเป็น 2 ชิ้น | แยกเป็นเส้นพับ **ไม่ตัด** เก็บไว้ใช้มาร์ค | ข้อมูล · เส้นประเขียว |
| เส้นพับบนเลเยอร์ BEND / พับ / CENTER หรือเส้นประ | – (ไม่ถูกตัดอยู่แล้ว) | เก็บเป็นเส้นพับของชิ้นนั้น ใช้มาร์คได้ | ข้อมูล |
| เส้นช่วย/เส้นเกินในชิ้นงาน (เช่น เครื่องหมายศูนย์รู `+`) | เครื่องตัดเป็นรอยในชิ้นงาน | ลบออก | แก้แล้ว · เส้นประแดง |
| ตัวเลข/ตัวอักษรที่ระเบิดเป็นเส้น (`90` ที่ลืมลบ) | เครื่องตัดเป็นรูรูปตัวเลข / ชิ้นงานอ่านผิดเป็นกรอบ | ลบออก (ดูเกณฑ์ข้อ 3) | แก้แล้ว · เส้นจุดแดง |
| ข้อความ `90`, `90°`, `UP 90° R 0`, `R5`, `Ø10` ในชิ้นงาน | ซอฟต์แวร์บางตัวนำข้อความเข้าไปตัด/มาร์ค | ไฟล์ที่ส่งให้เครื่องมีเฉพาะเส้นตัด | ข้อมูล |
| มุมห่างเกินค่าที่ตั้ง / เส้นไม่ปิดวง | ชิ้นนั้นตัดไม่ได้ | **ไม่เดา** – แสดงความยาวเส้นและระยะห่างของปลายเส้น | ต้องแก้แบบ · สีแดง |
| เส้นโค้ง/หลายเส้นในชิ้นงานที่ไม่ปิด (อาจเป็นรูที่ต่อไม่สนิท) | รูหาย | ไม่ตัด แต่เตือนให้ตรวจ | ต้องแก้แบบ |

แบบประกอบที่มีตาราง BOM ไม่ถูกแก้เส้น (ชิ้นส่วนอ่านจากตาราง ไม่ใช่จากภาพประกอบ)

## 2. หน้าต่างนำเข้าแบบ → แท็บ *ตรวจแบบก่อนตัด*

![](screenshots/7d_dwg_precut_check.png)

- หัวแท็บบอกจำนวน: `ตรวจแบบก่อนตัด (แก้ 11 · ต้องแก้ 1)` และช่อง *ตรวจเส้นตัด* ด้านขวาบนสรุปเหมือนกัน
- ตาราง: **ผล** (ต้องแก้แบบ / แก้แล้ว / ข้อมูล) · **รายการ** · **ชิ้นงาน** (รหัสจากป้าย) · **รายละเอียด** (เช่น `ห่าง 0.30 มม. – ต่อให้แล้ว`) · **ตำแหน่ง X, Y** ในแบบ
- **คลิกแถว** → ภาพซูมไปที่จุดนั้นพร้อมวงเหลือง

  ![](screenshots/7e_dwg_precut_zoom.png)

- **แก้เส้นอัตโนมัติ** + **ต่อปลายเส้นที่ห่างไม่เกิน … มม.** → กด **ตรวจใหม่** เพื่ออ่านแบบนี้ใหม่ด้วยค่าที่ตั้ง
  (ปิด = อ่านตามที่วาด เพื่อเทียบ · เพิ่มค่า = ต่อมุมที่ห่างกว่าเดิม เช่น 3.5 มม.)
- **บันทึกแบบที่แก้แล้ว (DXF)…** → ไฟล์ `<ชื่อแบบ>_CUT.dxf` ตำแหน่งเดิม มีเฉพาะเส้นตัดที่ปิดวงแล้ว
  (รอบนอก/รู แยกเลเยอร์และสีตาม *ค่าเครื่องตัด*) ใช้เปิดในซอฟต์แวร์ของเครื่อง หรือส่งกลับให้ฝ่ายเขียนแบบ
- ค่าเริ่มต้นตั้งที่หน้า **ตั้งค่า → การอ่านรูปคลี่ชิ้นงาน → ตรวจแบบก่อนตัด**
- รายการที่แก้จะติดไปกับชิ้นงาน (Part List, คลังรูปคลี่) และขึ้นในแท็บ **ตรวจก่อนตัด** ของหน้าเลเซอร์เป็นระดับ *แก้แล้ว*
  ส่วนที่ต้องตรวจเป็นระดับ *ควรตรวจ*

## 3. หลักการ – แก้เท่าที่มั่นใจ ไม่เดา

1. เส้นที่ปิดวงอยู่แล้วไม่ถูกแตะ (ยกเว้นวงซ้อนซ้ำและตัวอักษรที่เป็นเส้น)
2. เส้นที่ไม่ปิดวง: ตัดแบ่งที่จุดตัดกัน → รวมเส้นซ้ำ → ต่อปลายที่ห่างไม่เกินค่าที่ตั้ง (คู่ที่ใกล้ที่สุดก่อน)
   → ตัดปลายที่ยื่นเกินมุม → เส้นที่ยังมีปลายลอยถูกนำออก → หาพื้นที่ปิดที่เหลือเป็นรูปคลี่และรู
3. **เส้นพับ** = เส้นตรงที่แบ่งชิ้นงานจากขอบถึงขอบ (ปลายทั้งสองอยู่บนขอบชิ้นไม่เกิน 2 มม.)
   ถ้าเป็น *สองชิ้นวาดติดกัน* จริง ให้แยกชิ้นในแบบ (ระบบจะถือเป็นชิ้นเดียวมีเส้นพับ)
4. **ตัวอักษรที่เป็นเส้น**: วงเล็ก (ไม่เกิน 30 มม. และเล็กกว่าครึ่งของชิ้นงาน) อยู่ในชิ้นงาน เรียงติดกันเหมือนตัวอักษร
   และมีลักษณะตัวอักษร (มีวงในเช่น `0 8 9`, รูปเว้า หรือเส้นโค้งเปิด) – **รูกลมไม่ถูกนับเป็นตัวอักษรเสมอ**
   รู/ช่องสี่เหลี่ยม/ร่องยาวที่เรียงกันก็ไม่ถูกนับ เพราะไม่มีลักษณะตัวอักษร
   **ไม่ลบ – ตัดตามแบบ** (ขึ้นเป็น *คงตัวอักษร/ลวดลายที่ตัดในชิ้นงาน* ในแท็บตรวจแบบ):
   * **โลโก้ RRS** – ลวดลายที่มีรูเล็กแบบเรียบ ๆ อัดกันเป็นกลุ่ม (รังผึ้งรอบตัวอักษร RRS) ≥ 12 รู
   * **ตัวอักษรที่ตัดเป็นของชิ้นงาน** เช่น stencil `RUNGRUENG` – ชิ้นส่วนตัวอักษรที่อยู่แถวเดียวกับตัวอักษรใหญ่
     ที่เป็นรูตัดของชิ้นงานเดียวกัน (ตัว G ที่แยกเป็น 2 ชิ้นจึงไม่หาย)
   * **รูยาวปลายมน (slot)** เช่นรูของชิ้นเต้า และ **รู/ช่องที่มีบอกขนาด (dimension) ในแบบ** – เป็นรูตัดจริงเสมอ
   ตัวเลข/คำที่อยู่ลอย ๆ ในชิ้นงาน เช่น `90` ยังลบออกเหมือนเดิม
5. ทุกการแก้มีตำแหน่งและขนาด ตรวจย้อนได้ในตาราง และกด *ตรวจใหม่* แบบปิดการแก้เพื่อเทียบได้

## 4. ก่อนส่งตัด – ค่าเครื่องตัด → แท็บ *ก่อนส่งตัด (Mark · Nest · Gap)*

![](screenshots/14f_laser_precut_settings.png)

### Mark – มาร์คบนชิ้นงาน (เลเยอร์ `MARK`)

| ค่า | ตัวเลือก | ในไฟล์ |
|---|---|---|
| มาร์ครหัสชิ้นงานบนชิ้น | เปิด/ปิด | ข้อความรหัสกลางชิ้น |
| เส้นพับ | ไม่มาร์ค · **มาร์คปลายเส้นพับ** (ขีดสั้นที่ขอบทั้งสองด้าน) · มาร์คเต็มเส้น | `LINE` บนเลเยอร์ MARK |
| ความยาวขีดที่ขอบ | 10 มม. (ไม่เกิน 1/3 ของเส้นพับ) | |

ช่างพับเห็นตำแหน่งพับบนชิ้นงานทันที ไม่ต้องวัดเอง · **ก่อนเปิดใช้** ต้องตั้งเลเยอร์ `MARK` ในซอฟต์แวร์ของเครื่อง HSG
เป็นงาน *Mark* (กำลังต่ำ ไม่ตัดขาด) – ทดสอบด้วย **ส่งออก ▾ → ไฟล์ทดสอบเลเยอร์** มิฉะนั้นเครื่องจะตัดตามเส้นมาร์ค

### Nest – วางชิ้นงานบนแผ่น

| ค่า | ค่าเริ่มต้น | ผล |
|---|---|---|
| ระยะห่างชิ้นงาน (หน้าวางแผนตัด) | 5 มม. | ระยะขั้นต่ำทุกความหนา |
| แผ่นหนา = ความหนา × | 1.0 | แผ่น 12 มม. ห่าง 12 มม. · แผ่น 3 มม. ใช้ 5 มม. ตามขั้นต่ำ (กันความร้อนทำชิ้นข้างเคียงเสียรูป) |
| หมุนชิ้นที่วาดเอียง | เปิด | ชิ้นที่วาดเอียง (เช่น 30°) หมุนให้ได้สี่เหลี่ยมตั้งต้นเล็กที่สุดก่อนวาง เส้นพับหมุนตาม |
| ขอบแผ่น / หมุน 90° | 10 มม. / ได้ | ตั้งที่หน้าวางแผนตัด |

ขนาดแผ่นยังเลือกจากรายการเหล็กแผ่นในสต็อกที่ใช้เหล็กน้อยที่สุด (LASER_CUTTING ข้อ 3)

### Gap / Micro-joint – เว้นไม่ตัดบางจุดให้ชิ้นติดแผ่น

| ค่า | ค่าเริ่มต้น | หมายเหตุ |
|---|---|---|
| ใส่ที่ | **ไม่เว้น** · เฉพาะชิ้นเล็ก · ทุกชิ้น | ชิ้นเล็กกระดก/ตกร่องโต๊ะ, ชิ้นบางบิดตอนตัด |
| ชิ้นเล็ก = ด้านยาวน้อยกว่า | 150 มม. | |
| ความกว้างที่เว้น | 0.5 มม. | |
| จำนวนจุดต่อชิ้น | อัตโนมัติ | 1 จุด = Gap ที่ปลายเส้นตัด · อัตโนมัติ: 2 จุด (รอบชิ้นไม่เกิน 600 มม.) แล้วเพิ่ม 1 จุดทุก 600 มม. สูงสุด 8 |

ระบบวางจุดเว้นไว้ **กลางด้านตรงที่ยาวที่สุด** กระจายรอบชิ้น (ชิ้นกลมกระจายเท่ากัน) เฉพาะรอบนอก – รูในตัดขาดตามปกติ
ในไฟล์ รอบนอกจะเป็นเส้นเปิดหลายเส้น: **ปิดตัวเลือก "ต่อเส้นอัตโนมัติ/Auto close" ตอนนำเข้าในซอฟต์แวร์ของเครื่อง**
หรือเลือก *ไม่เว้น* แล้วใส่ Gap/Micro-joint ในซอฟต์แวร์ของเครื่องแทน · หน้าตรวจก่อนตัดบอก *เว้น Gap/micro-joint … จุดให้แล้ว* ที่ชิ้นเล็ก

## 5. ไฟล์ที่ได้

| เลเยอร์ (สี) | เนื้อหา |
|---|---|
| `CUT_OUTER` (แดง) | รอบนอก – เส้นปิด หรือเส้นเปิดเมื่อมี Gap/micro-joint |
| `CUT_INNER` (ฟ้า) | รู/ช่องใน (รูกลมเป็น `CIRCLE`) |
| `MARK` (เขียว) | รหัสชิ้นงาน · เส้นพับ (ขีดที่ขอบ หรือเต็มเส้น) |

ไม่มีข้อความ ขนาด ตัวเลขมุมพับ กรอบแบบ หรือเส้นที่ถูกนำออกในไฟล์ · ภาพแผ่นในใบสั่งตัดแสดงเส้นพับเป็นสีเขียวเมื่อเปิดมาร์ค

## 7. คำแนะนำฝ่ายเขียนแบบ (ลดจุดที่ต้องแก้)

1. วาดรูปคลี่เป็น Polyline ปิด บนเลเยอร์ `CUT` · เส้นพับบนเลเยอร์ `BEND` (หรือเส้นประ)
2. ข้อความ/ขนาด/มุมพับ ไว้บนเลเยอร์ `TEXT` / `DIM` – **ไม่ Explode ข้อความ**
3. ใช้คำสั่งตรวจเส้นซ้ำ (OVERKILL) และ Join ก่อนส่งแบบ
4. ป้ายชิ้นงาน `รหัส / ชื่อ / t ความหนา / จำนวน ชิ้น / M=วัสดุ` ไว้ในหรือชิดรูปคลี่ (DWG_INTEGRATION ข้อ 3.1)

## 8. ระยะต่อไป

- Nest แบบตามรูปร่างจริง: วางชิ้นเล็กในรูใหญ่ของชิ้นอื่น, จับคู่ชิ้นรูปตัว L/สามเหลี่ยมกลับหัว, ตัดเส้นร่วม (common line)
- ตั้งชื่อเลเยอร์/สีตามที่ซอฟต์แวร์ HSG แยกงานได้จริง หลังได้ผลทดสอบ `LAYER_TEST.dxf`
- อ่านทิศพับ (`UP` / `DOWN`) จากข้อความข้างเส้นพับ แล้วมาร์คต่างกัน
