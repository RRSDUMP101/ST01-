# นำข้อมูลเข้า Express: เทียบวิธี และระบบคีย์อัตโนมัติ

Express (NewRWT) เป็นโปรแกรมบนฐานข้อมูล Visual FoxPro (ไฟล์ .DBF บน `\\<เครื่องเซิร์ฟเวอร์>\<โฟลเดอร์แชร์>\ExpressA\…` – แต่ละบริษัท/ปีเป็นโฟลเดอร์ เช่น `ffff`, `RRSDP69`)
**ไม่มี API** และ **นำเข้าเอกสารซื้อ/ขาย/เบิก จากโปรแกรมอื่นไม่ได้** (ข้อมูลจากตัวแทนจำหน่าย: นำเข้าได้เฉพาะข้อมูลหลัก
เช่น สินค้า ผู้จำหน่าย ผ่าน Excel ที่ต้องแปลงด้วย Visual FoxPro)

## 1. เทียบ 5 วิธี

| วิธี | ทำอย่างไร | ข้อดี | ข้อเสีย / ความเสี่ยง | สรุป |
|---|---|---|---|---|
| A. คีย์เองจากไฟล์ส่ง Express | หน้า Express → **ส่งออกไฟล์ส่ง Express** (ชีทละใบตามหน้าจอ) แล้วคีย์ | ปลอดภัย ไม่ต้องตั้งค่า | ช้า คีย์ผิดได้ | ใช้ได้ทันที (มีแล้ว) |
| B. นำเข้าข้อมูลหลักของ Express (Excel) | ทะเบียนสินค้า/ผู้จำหน่าย ผ่านเครื่องมือของ Express/ตัวแทน | ได้ทีละมาก | **ไม่รองรับเอกสาร** PD/OU/RR/FR · ต้องให้ตัวแทนแปลงไฟล์ | เฉพาะรหัสใหม่จำนวนมาก |
| C. เขียนลงไฟล์ DBF โดยตรง | ODBC / FoxPro เขียนตารางของ Express | เร็วที่สุด | **เสี่ยงสูง**: ข้าม logic ของ Express (เลขที่, ต้นทุน FIFO, ยอดคลัง, ลงบัญชี, ดัชนี CDX, ล็อกระเบียนตอนหลายคนใช้) ข้อมูลเสียกู้ยาก หมดการดูแลจากผู้ขาย | **ไม่แนะนำ** |
| D. **คีย์อัตโนมัติ (RPA)** – แบบในคลิป AccAiBot / ACCOS RPA | โปรแกรมพิมพ์ลงหน้าจอ Express เหมือนคน (คีย์บอร์ด) | ไม่ต้องใช้ API · Express ตรวจทุกช่อง ออกเลขที่ คิดต้นทุน ลงบัญชีเอง = ปลอดภัยเท่าคนคีย์ · ใช้กับ Express บน Server เดิม | ต้องตั้งลำดับการกดให้ตรงหน้าจอครั้งแรก · ห้ามใช้เครื่องระหว่างคีย์ | **แนะนำ** (สร้างแล้ว) |
| E. อ่าน DBF แบบอ่านอย่างเดียว | อ่านยอดคงเหลือ/เลขที่เอกสารจาก Express กลับมา | ไม่แตะข้อมูล · ได้เลขที่ Express อัตโนมัติ | ต้องรู้โครงสร้างตารางของรุ่นนี้ (ต้องมีสำเนาโฟลเดอร์ข้อมูลมาวิเคราะห์) | ขั้นถัดไป |

**ที่ใช้ร่วมกันดีที่สุด:** D (ส่งเข้า) + A (สำรอง/ตรวจ) + นำเข้ารายงาน Express (กลับ, มีแล้ว) → ต่อไป E เพื่ออ่านเลขที่กลับเอง

## 2. คีย์เข้า Express อัตโนมัติ (ในโปรแกรม)

หน้า **Express → ส่งเข้า Express → คีย์เข้า Express อัตโนมัติ…** (บน Windows เครื่องที่เปิด Express)

1. เปิด Express ที่หน้าจอเอกสารชนิดนั้น (เช่น 4.สินค้า → PD - จ่ายวัตถุดิบเพื่อผลิต)
2. ติ๊กใบที่จะคีย์ (ใบที่ **คีย์แล้ว รอเลขที่** ไม่ถูกติ๊ก กันคีย์ซ้ำ) → **เริ่มคีย์เข้า Express**
3. โปรแกรมพิมพ์: เพิ่มใหม่ → แผนก → หมายเหตุ (งาน/SO + หมายเหตุ) → วันที่ → รายการสินค้า <F8> → รหัส/คลัง/จำนวน ทีละบรรทัด
4. **หยุดก่อนบันทึกทุกใบ** ({STOP}): ตรวจในหน้าจอ แล้วกดบันทึกใน Express เอง → ใส่เลขที่ที่ Express ออกให้ → OK = คีย์ใบถัดไป
5. ใบที่ได้เลขที่แล้วออกจากรายการ ส่งออก/ประวัติมีเลขที่ Express

**ความปลอดภัย:** หยุดทันทีเมื่อ (1) เลื่อนเมาส์ไปมุมซ้ายบนสุดของจอ (2) หน้าต่าง Express ไม่ได้อยู่ด้านหน้า (ไม่พิมพ์ผิดที่)
(3) กด **หยุด** · ไม่บันทึกแทนคน (เว้นแต่แก้แบบการกดให้กดบันทึกเอง) · ไม่แตะไฟล์ข้อมูลของ Express

### ตั้งลำดับการกดครั้งแรก (ทำครั้งเดียวต่อหน้าจอ)

ลำดับที่ให้มาเป็นค่าตั้งต้นจากภาพหน้าจอ Express ของบริษัท **ต้องทดลองกับหน้าจอจริงก่อน**

1. ทดลองกับ Notepad: เปิด Notepad → ในช่อง *พิมพ์ลงหน้าต่างที่ชื่อมี* ใส่ `Notepad` (หรือ `Untitled`) → เริ่มคีย์ → ดูสิ่งที่พิมพ์
2. ทดลองกับ Express ด้วยใบเดียว: ดูว่าเคอร์เซอร์ไปช่องถูกหรือไม่ → แก้แบบการกด เช่น เพิ่ม `{TAB}` / `{ENTER}` / `{WAIT 800}`
3. ปุ่มที่ใช้: `[แผนก] [หมายเหตุ] [วันที่] [งาน] [ผู้จำหน่าย] [อ้างอิง]` · บรรทัด `[รหัส] [คลัง] [จำนวน] [หน่วย] [ราคาต่อหน่วย]` ·
   `{ENTER} {TAB} {ESC} {DOWN} {F4} {F8} {F10} {CTRL+S} {TAB 3}` · `{WAIT 500}` · `{STOP}`
4. ภาษาไทยเป็นตัวอ่านไม่ออก: ติ๊ก **พิมพ์ภาษาไทยด้วยการวาง (Ctrl+V)** หรือสลับแป้นพิมพ์เป็นไทยในหน้าจอ Express ก่อนเริ่ม

### ส่งออก AutoHotkey

ปุ่ม **ส่งออก AutoHotkey…** เขียนสคริปต์ AutoHotkey v2 ของการกดเดียวกัน ให้ IT ตรวจดู หรือรันบนเครื่องที่ไม่มีโปรแกรมนี้
(หยุดถามทุกใบเหมือนกัน · Ctrl+Alt+Q = หยุด)

## 3. ขั้นต่อไป (ต้องการข้อมูลจากบริษัท)

* สำเนาโฟลเดอร์ข้อมูล Express (คัดลอกตอนปิดโปรแกรม ไม่ใช้ตัวจริง) → ทำ **อ่าน DBF อย่างเดียว**: เลขที่ Express ของใบที่คีย์ ยอดคงเหลือสด
  ตรวจว่าใบในโปรแกรมกับใน Express ตรงกัน (วิธี E)
* วิดีโอ/ลำดับปุ่มจริงของหน้าจอ PD, OU, RR (ใบเดียว) → ปรับค่าตั้งต้นของแบบการกดให้ใช้ได้ทันที
