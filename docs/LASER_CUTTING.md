# จากแบบ DWG สู่เครื่องตัดเลเซอร์ – ระบบและวิธีใช้งาน

ต่อจากขั้นตอนนำเข้าแบบ DWG ที่ผู้ออกแบบใช้งานจริงแล้ว ([DWG_INTEGRATION.md](DWG_INTEGRATION.md))
ระบบนี้ทำให้รูปคลี่ในแบบไปถึงเครื่องตัดเลเซอร์โดยไม่ต้องวาดหรือพิมพ์ซ้ำ ทุกขั้นอยู่ในหน้า **ตัดเหล็ก / เลเซอร์**

```
ผู้ออกแบบ: แบบ DWG (รูปคลี่ + ป้าย รหัส / ชื่อ / ความหนา / จำนวน)
   │  นำเข้าแบบ (หน้า แบบ 2D)
   ▼
คลังรูปคลี่ ─ รูปคลี่ล่าสุดของทุกรหัส (นำเข้า Rev. ใหม่ ทับของเดิม)
   │  วางแผนตัด
   ▼
สิ่งที่ต้องตัด = งานผลิตที่เปิดอยู่ (ชิ้นที่ยังไม่ผ่านขั้นตัด − ที่อยู่ในโปรแกรมตัดแล้ว)  หรือ  Part List × จำนวนคัน
   │  ตรวจก่อนตัด (รูเล็ก, รูชิดขอบ, ชิ้นเล็ก, เส้นซ้อน, ไม่มีความหนา, ใหญ่กว่าแผ่น/โต๊ะเครื่อง)
   ▼
วางชิ้นงานบนแผ่นแยกวัสดุ / ความหนา → โปรแกรมตัด LC… (แผ่นที่วางเหมือนกันรวมเป็น 1 โปรแกรม × N แผ่น)
   │  ส่งออกไฟล์เลเซอร์
   ▼
โฟลเดอร์ LaserPackage_… : DXF ต่อโปรแกรม + DXF รายชิ้น + ภาพ PNG + ใบสั่งตัดเลเซอร์ (Excel)
   │  ช่างเลเซอร์เปิดไฟล์ในซอฟต์แวร์ของเครื่อง แล้วตัด
   ▼
คิวเลเซอร์: รอตัด → กำลังตัด → ตัดแล้ว
   └─ บันทึกตัดเสร็จ → ชิ้นส่วนในงานผลิตผ่านขั้น "ตัด" (สถานะเป็น รอพับ) + ร่าง PD จ่ายแผ่นเหล็กให้สโตร์
```

## 1. ใครทำอะไร

| ขั้น | ผู้รับผิดชอบ | หน้าในโปรแกรม | ผลลัพธ์ / จุดตรวจ |
|---|---|---|---|
| เขียนแบบ ใส่ป้ายรูปคลี่ | ผู้ออกแบบ | ZWCAD | รูปคลี่เป็นเส้นปิด, ป้าย รหัส/ชื่อ/ความหนา/จำนวน |
| นำเข้าแบบ ตรวจรหัส/ความหนา/จำนวน | ผู้ออกแบบ หรือ วางแผนผลิต (แอม) | แบบ 2D | Part List + **คลังรูปคลี่** |
| เปิดงานผลิต (SO) | วางแผนผลิต (แอม) | งานผลิต (SO) | ชิ้นที่ต้องผลิต รอตัด |
| วางแผนตัด + สร้างโปรแกรม | วางแผนผลิต (แอม) | ตัดเหล็ก / เลเซอร์ → วางแผนตัด | โปรแกรม LC… เข้าคิว |
| ตรวจก่อนตัด | วางแผนผลิต + หัวหน้าเลเซอร์ | ตรวจก่อนตัด | แก้แบบ หรือยอมรับคำเตือน |
| ส่งออกไฟล์ + ใบสั่งตัด | วางแผนผลิต | ส่งออก ▾ | LaserPackage ให้ช่างเลเซอร์ |
| ตัด + บันทึกผล | ช่างเลเซอร์ | คิวเลเซอร์ → บันทึกตัดเสร็จ | จำนวนแผ่นที่ตัด, ผู้ตัด, เศษแผ่น |
| จ่ายแผ่นเหล็ก | สโตร์ (แอน 2) | เบิก/รับ สต็อก | ตรวจร่าง PD แล้วบันทึก + คีย์ Express |

## 2. แบบ DWG ที่ใช้ตัดได้ (สิ่งที่ผู้ออกแบบทำอยู่แล้ว)

- รูปคลี่ 1:1 หน่วยมิลลิเมตร เป็น **เส้นปิด** (Polyline ปิด หรือเส้น/โค้งที่ต่อกันครบวง)
- รูและช่องในชิ้นงานวาดเป็นวงกลม หรือเส้นปิดภายในรูปคลี่
- ป้ายข้อความใกล้รูปคลี่ เช่น `RRS-T-001` · `เฟรมบน` · `t3` · `16 ชิ้น` (รายละเอียดใน DWG_INTEGRATION ข้อ 3.1)
- เส้นที่ยังไม่เรียบร้อย (มุมต่อไม่สนิท เส้นยื่นเกิน เส้นซ้ำ เส้นพับ/เส้นช่วยบนเลเยอร์ตัด ตัวเลข `90` ที่ลืมลบ)
  โปรแกรม **แก้ให้เองตอนนำเข้า** และแสดงทุกจุดในแท็บ *ตรวจแบบก่อนตัด* – ส่วนที่แก้เองไม่ได้ (เช่น มุมห่างเกิน 0.5 มม.)
  ขึ้น **วงแดง** ในภาพให้แก้ในแบบ รายละเอียด: [PRE_CUT_CHECK.md](PRE_CUT_CHECK.md)
- ถ้าแบบมีเส้นอื่นปน ให้วาดรูปคลี่บนเลเยอร์เดียว (เช่น `CUT`) แล้วตั้งชื่อเลเยอร์ในหน้า **ตั้งค่า → เลเยอร์เส้นตัด**
- นำเข้าแบบแล้ว โปรแกรมเก็บรูปคลี่ไว้ใน **คลังรูปคลี่** ตามรหัส (แท็บสุดท้ายของหน้า ตัดเหล็ก / เลเซอร์)
  งานผลิตครั้งต่อไปที่ใช้รหัสเดิมจึงตัดได้ทันทีโดยไม่ต้องนำเข้าแบบซ้ำ

## 3. วางแผนตัด

- **แหล่งงาน**
  - *งานผลิตที่เปิดอยู่* – ติ๊กงานที่จะตัดรวมกัน (งานใหม่ถูกติ๊กให้เอง)
  - *Part List ปัจจุบัน* × จำนวนคัน – ใช้ตอนยังไม่เปิดงาน
- **จำนวนที่ต้องตัด** = ต้องผลิต − ตัดแล้ว − อยู่ในโปรแกรมที่ยังไม่ตัด จึงไม่วางชิ้นเดิมซ้ำ
- รหัสที่ไม่มีรูปคลี่ในคลัง แสดงเป็นรายการ *ไม่มีรูปคลี่* ให้นำเข้าแบบก่อน
- ค่าที่ปรับได้: ระยะห่างชิ้น (เริ่มต้น 5 มม. · แผ่นหนาใช้ ความหนา × 1.0 ถ้ามากกว่า), ระยะขอบแผ่น (10 มม.), หมุนชิ้นได้,
  หมุนชิ้นที่วาดเอียงให้ได้แผ่นตั้งต้นเล็กที่สุด, ความหนาเมื่อแบบไม่บอก (ค่าเครื่องตัด → *ก่อนส่งตัด*)
- **แผ่นเหล็ก**: ใช้ขนาดจากรายการเหล็กแผ่นในสต็อกที่วัสดุและความหนาตรงกัน (ขนาดในชื่อ เช่น `1219x2440`)
  ถ้าไม่มี ใช้ 4x8 ฟุต (1219 × 2440) และ 5x10 ฟุต (1524 × 3048) · บวกขนาดที่ *เพิ่มเอง* ทุกขนาด
  แล้วเลือกขนาดที่ใช้เนื้อเหล็กน้อยที่สุดให้เอง (อัตโนมัติ)
- **เลือก / เปลี่ยนแผ่นเหล็ก**: ช่อง **แผ่นที่ใช้** ในตารางแผนตัดเป็นรายการเลือก (Dropdown) ของแต่ละวัสดุ/ความหนา
  (หรือเลือกแถวแล้วใช้ช่อง **ขนาดแผ่นของแถวที่เลือก** ด้านบน – สองช่องนี้ตรงกันเสมอ)
  - รายการมาจาก **สต็อกเหล็ก** ทีละรหัส: `รหัส ชื่อสินค้า · กว้าง x ยาว มม. · คงเหลือ N แผ่น` (ขนาดจากคอลัมน์ กว้าง/ยาว
    ของไฟล์สต็อกเหล็ก ถ้าไม่มีอ่านจากชื่อ) ตามด้วย *เพิ่มเอง* · *ขนาดมาตรฐาน (ไม่มีในสต็อก)*
  - แผ่นขนาดเดียวกันหลายรหัส เลือกรหัสที่ต้องการได้ · โปรแกรมเลือกเองใช้รหัสที่คงเหลือมากกว่า
  - แผ่นตะแกรง / ตีนไก่ / ตีนเป็ด / เจาะรู อยู่ท้ายรายการ เลือกเองได้ แต่โปรแกรมไม่เลือกให้อัตโนมัติ
  - โปรแกรมตัดที่สร้างจากแผนจำรหัสแผ่นไว้ แท็บ **สต็อกเหล็ก** ของสโตร์จึงเห็นว่าคิวเลเซอร์ต้องใช้แผ่นไหนกี่แผ่น
  - เลือกแล้ววางใหม่ทันทีเฉพาะวัสดุ/ความหนานั้น (แถบล่างบอกจำนวนแผ่นและ % ใช้เหล็ก) · ชิ้นที่ใหญ่กว่าแผ่นที่เลือก
    ไปวางบนขนาดที่ใหญ่กว่าที่มีให้เอง · เลือก *อัตโนมัติ* เพื่อกลับไปใช้ขนาดที่ใช้เหล็กน้อยที่สุด
  - **ทุกแถวมี Dropdown** รวมแถวที่ 2, 3 … ของความหนาเดียวกัน (แผ่นของ *ชิ้นที่ใหญ่เกินแผ่นหลัก*): รายการมีเฉพาะแผ่นที่
    ชิ้นเหล่านั้นวางได้ทุกชิ้น (รหัส · ขนาด · คงเหลือ) · เลือกแล้ว แผ่นหลักคงเดิม (ถูกตรึงไว้ ไม่สลับไปขนาดอื่น)
    ช่อง *รหัสแผ่น* / *ขนาดแผ่น* ของแถวนั้นเปลี่ยนตาม · *อัตโนมัติ* = แผ่นเล็กสุดที่ชิ้นใหญ่วางได้

    ![](screenshots/14k_laser_overflow_sheet.png)

  - ขนาดที่เลือกจำไว้จนปิดโปรแกรม กดคำนวณแผนตัดใหม่ก็ยังใช้ขนาดเดิม

  ![](screenshots/14i_laser_sheet_choice.png)
  ![](screenshots/14j_laser_sheet_dropdown.png)

- **ขนาดแผ่นเพิ่มเอง…** – เพิ่มขนาดแผ่นที่วางแผนได้ นอกจากที่มีในสต็อก (เช่น ขนาดที่สั่งซื้อได้ หรือแผ่นที่ยังไม่มีรหัส)
  - เลือกจากขนาดที่ใช้บ่อย (4x8, 4x10, 5x10, 5x20 ฟุต, 1500x3000, 1500x6000, 2000x6000) หรือพิมพ์กว้าง × ยาวเอง
  - *หนา* = 0 ใช้กับทุกความหนา หรือใส่ความหนาเพื่อใช้เฉพาะความหนานั้น · *หมายเหตุ* แสดงต่อท้ายในรายการ
  - ขนาดที่ใหญ่กว่าโต๊ะเครื่อง (ค่าเครื่องตัด) ขึ้นสีแดง และ *ตรวจก่อนตัด* แจ้ง *ต้องแก้* ถ้าแผนใช้ขนาดนั้น
  - บันทึกในเครื่องนี้ ใช้กับทุกแผนตัดต่อไป · ขนาดที่เพิ่มเองไม่มีรหัสสต็อก ใบ PD ของสโตร์จึงต้องใส่รหัสแผ่นเอง

  ![](screenshots/14h_laser_sheet_sizes.png)

- กด **สร้างโปรแกรมตัด → คิวเลเซอร์** แผ่นที่วางเหมือนกันทุกชิ้นรวมเป็นโปรแกรมเดียว × จำนวนแผ่น
- **เพิ่มชิ้นลงที่ว่าง…** (Nest เอง) – ที่หน้าวางแผนตัด (เลือกแถวแผน แล้วเลือกแผ่น) หรือที่คิวเลเซอร์ (โปรแกรมที่ยังรอตัด):
  เลือกชิ้นจากคลังรูปคลี่ที่ **วัสดุและความหนาเดียวกับแผ่น** ใส่จำนวนต่อแผ่น (หรือ *เต็มที่ว่าง*) – ภาพแสดงที่ว่าง (กรอบเขียว)
  และชิ้นที่จะเพิ่ม (สีเขียว) ก่อนกดเพิ่ม · ชิ้นเดิมไม่ขยับ เว้นระยะห่างชิ้น/ขอบแผ่นตามค่าที่ตั้ง · ในคิวเลเซอร์เพิ่มให้ทุกแผ่นของโปรแกรม
  และคำนวณเวลาตัด / % ใช้เหล็กใหม่ · ชิ้นที่เพิ่มเองไม่ผูกกับงานผลิต (ตัดเก็บสต็อก/สำรอง) บันทึกตัดแล้วจึงไม่ลงงาน

  ![](screenshots/14g_laser_fill_free_space.png)

## 4. ตรวจก่อนตัด

| ตรวจ | เกณฑ์ (ปรับได้ใน **ค่าเครื่องตัด…**) | ระดับ | ทำอย่างไร |
|---|---|---|---|
| ไม่มีความหนา | – | ต้องแก้ | ใส่ความหนาในแบบ หรือในหน้า Part List |
| ความหนาไม่อยู่ในตารางความเร็ว | – | เตือน | เพิ่มแถวในตารางความเร็ว (เวลาตัดยังเป็นค่าประมาณ) |
| รูเล็กกว่าความหนา | ขนาดรู < ความหนา × 1.0 | เตือน | รูอาจไม่กลม/ไม่ทะลุ – พิจารณาเจาะแทน |
| รูชิดขอบ | ระยะรู–ขอบ < ความหนา × 1.0 | เตือน | ขอบอาจละลาย/บิด – ขยับรูในแบบ |
| ชิ้นเล็ก | ด้านยาว < 25 มม. | เตือน | อาจกระดก/ตกร่องโต๊ะ – เปิด Gap/micro-joint (ขึ้นเป็น *แก้แล้ว* เมื่อเว้นให้แล้ว) |
| แบบถูกแก้อัตโนมัติตอนนำเข้า | ต่อมุม ตัดเส้นเกิน ลบเส้นซ้ำ/ตัวอักษร | แก้แล้ว | ไม่ต้องทำ – แจ้งให้รู้ และส่งกลับฝ่ายเขียนแบบ |
| เส้นในชิ้นงานไม่ปิด | อาจเป็นรูที่ต่อไม่สนิท | เตือน | ตรวจว่าขาดรูหรือไม่ แก้ในแบบ |
| เส้นซ้อน | วงเดียวกันวาดซ้ำ | เตือน | เลเซอร์จะตัดซ้ำ – ลบเส้นซ้ำในแบบ |
| ใหญ่กว่าแผ่น | – | ต้องแก้ | เลือกแผ่นใหญ่ขึ้น หรือแบ่งชิ้น |
| ใหญ่กว่าโต๊ะเครื่อง | ชิ้นหรือแผ่นเกิน 8,000 × 2,500 มม. (ตั้งได้) | ต้องแก้ | แบ่งชิ้น / ใช้แผ่นเล็กลง |

ไฟล์ที่ส่งออกอ่านกลับเข้าโปรแกรมได้ครบ (ทดสอบแล้ว: ชิ้นและรูครบทุกชิ้น)
ค่าเฉพาะเครื่อง ได้แก่ lead-in/lead-out, ชดเชยความกว้างรอยตัด (kerf), ลำดับการตัด และ G-code
ให้ซอฟต์แวร์ของเครื่องใส่ตามค่ามาตรฐานของเครื่อง โปรแกรมนี้ไม่สร้าง G-code
(Mark · Nest · Gap ใส่จากโปรแกรมนี้ได้ หรือปิดไว้แล้วใช้ของซอฟต์แวร์เครื่อง – [PRE_CUT_CHECK.md](PRE_CUT_CHECK.md) ข้อ 4)

## 6. คิวเลเซอร์และการบันทึกผล

- เลขที่โปรแกรม **LC + ปี พ.ศ. 2 หลัก + เดือน + ลำดับ** เช่น `LC6910-0001`
- สถานะ **รอตัด → กำลังตัด → ตัดแล้ว** (หรือ ยกเลิก) · ภาระคิวแสดงที่หน้า ภาพรวม: *คิวเลเซอร์ N โปรแกรม · M แผ่น · ~H ชม.*
- **บันทึกตัดเสร็จ**: จำนวนแผ่นที่ตัด (ตัดไม่ครบในครั้งเดียวได้), ผู้ตัด, เศษแผ่นที่เหลือ เช่น `1219x600`
  - ชิ้นส่วนในงานผลิตผ่านขั้น *ตัด* ทันที (สถานะเปลี่ยนเป็น *รอพับ*)
  - ได้ **ร่าง PD** จ่ายแผ่นเหล็กตามจำนวนแผ่นที่ตัด ให้สโตร์ตรวจและบันทึกในหน้า เบิก/รับ สต็อก
- **เวลาตัด** = ระยะตัด ÷ ความเร็ว + จำนวนจุดเจาะ × เวลาเจาะ
  - บวกเวลาเดินหัว 15 % และเวลาเปลี่ยนแผ่น 3 นาทีต่อแผ่น
  - ใส่ค่าเครื่อง (บาท/ชม.) ในค่าเครื่องตัดแล้ว ใบสั่งตัดจะแสดงต้นทุนตัดด้วย
- ใบงานชิ้นส่วน (QR) ที่พิมพ์จากหน้า งานผลิต แสดงเลขโปรแกรม LC ที่มีชิ้นนั้นด้วย ช่างพับ/เชื่อมจึงตามชิ้นงานถูก

## 8. ข้อมูลที่ยังต้องการจากหน้างาน

1. ซอฟต์แวร์ที่ใช้เปิดไฟล์บนเครื่อง HSG และรุ่น DXF ที่เปิดได้
2. ชื่อเลเยอร์ที่ซอฟต์แวร์ใช้แยกขอบนอก/รูใน (ถ้าไม่ใช่ `CUT_OUTER` / `CUT_INNER`)
3. ขนาดแผ่นที่ใช้ประจำ (เครื่องรับได้ถึง 8,000 × 2,500 แผ่นใหญ่กว่า 5x10 ฟุตต้องมีในรายการสต็อก หรือเพิ่มใน *ขนาดแผ่นเพิ่มเอง…*)
   และขนาดเศษแผ่นที่เก็บไว้ใช้ต่อ
4. ตารางความเร็วและเวลาเจาะจริงตามความหนาที่ตัดบ่อย และค่าเครื่องต่อชั่วโมง (ถ้าต้องการเห็นต้นทุนตัด)

## 9. ระยะต่อไป

- นำเข้าเวลาตัดจริงจากรายงานของซอฟต์แวร์เครื่อง เพื่อปรับตารางความเร็วให้แม่นขึ้น
- ตัดท่อ (เครื่องรับท่อ Ø ถึง 325 มม.): รายการท่อที่ต้องตัดจากงานผลิต ความยาวรวม/จำนวนเส้น และไฟล์ให้เครื่อง
- เศษแผ่นเข้าสต็อกเป็นรายการ และนำมาใช้ในการวางแผนครั้งถัดไป
- สแกน QR ใบงานที่หน้าเครื่องเลเซอร์เพื่อบันทึก *กำลังตัด / ตัดแล้ว* (ตามแผนบันทึกหน้างานใน
